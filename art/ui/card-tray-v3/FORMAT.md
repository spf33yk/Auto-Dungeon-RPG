# card-tray/v3：余白を詰めたはめ込み用土台

2026-10-29。v2の共通形状・色と材質の差し替えを維持し、カード列の余白と前景の縁を調整した素材用フォーマット。ゲーム未適用。

- 左端128px、右端64pxを固定。中央は元画像のx=128から768pxを通常／反転交互で繰り返す。右端の不要な空き枠部分は反復素材にも含めない。
- 行高128px、行間8px。幅は116＋252×列数＋102。3列974×128、5列1478×128、5列3行1478×400px。
- fit.cardScale=0.30、cardAdvance=252、cardOriginX=103.1、cardOriginY=8.5。実際のカード輪郭と溝の間の余白は約8pxを基準にする。左右の数値は透明余白と終端の張り出しを含む組み立て用の値で、見た目の余白そのものではない。
- 土台、カード、前景の縁を別レイヤーで扱う。renderTrayLipが上側y=28と下側y=99へ高さ3pxの影と下側の細い明部を出力し、カードが溝に収まる表現にする。ゲームへ接続する際、縁レイヤーはpointer-events:noneにする。

生成は `node scripts/build-card-trays.js`。Sharpが利用できる環境では `--png` でPNGも出力。出力先はart/samples/card-tray-v3/。各テーマの3列1行／5列1行／5列3行に、土台と*-lipの前景を別保存する。4テーマ×3寸法×2レイヤー＝24点のSVG（PNG指定時は24点のPNGも）を生成する。

全テーマの共通枠はv1のclassic素材、内側の材質も既存4画像を再利用。新しい大容量原稿は追加しない。v1/v2の定義と原稿は保管し、旧版の再生成は定義・出力先を明示する。個別スキンで枠・番号欄・装飾のサイズを変更しない。

準備画面へ組み込む課題とUI変更案はdocs/ui/PREPARATION_CARD_UI_PROPOSAL.md。表示順、パネル開閉、横スクロール、数値編集、スキン保存は提案段階。現行のゲームUI・操作・能力・セーブは変更しない。
