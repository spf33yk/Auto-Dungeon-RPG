# card-tray/v2：全スキン共通の土台形状

現行素材は../card-tray-v3/FORMAT.md。v2を再生成するときは定義と出力先を明示する：`node scripts/build-card-trays.js art/ui/card-tray-v2/format.json art/samples/card-tray-v2`。以下は旧版の記録。

2026-10-29。v1ではPNGの外形と番号欄の比率がテーマごとに異なり、同じ画像寸法でも見た目のサイズが揃わなかった。v2は全テーマで**同じ枠画像・番号欄・切り出し・配置**を使い、金属色と内側の材質だけを交換する。

## サイズを固定する規則

- 行高128px、行間12px、番号中心(72,64)、番号文字40pxを全スキンで共用。
- 左右の端は元画像の各128pxを等倍で使用。テーマごとに端の形や大きさを変えない。
- 1列追加するごとに中央を280px延長し、端の装飾・カードは縮小しない。
- 幅は136＋280×列数＋136。3列1112px、5列1672px。行数が増えたときは128pxの行を追加。
- カード配置例は常に元PNGの28%で描画。3列／5列を同じキャンバス上で比較し、画像全体を同幅へ縮小して比較しない。

## 定義と組み立て

`format.json` の `frameImage` は全スキン共通の枠。既存v1のclassic素材を参照し、元ファイルを上書きしない。`skins.*.image` は材質の参照画像で、枠の外形には使用しない。`metalRamp` は枠の明暗を3色へ対応づける色指定で、形状とαを変えない。

`texture` は内側の共通領域。channelInset=108px、top=28px、height=72px。番号欄の材質も同じ位置・サイズで配置する。材質の反復開始位置を領域の上端へ揃え、領域途中に縦方向の繰り返し境界を作らない。

中央は通常／左右反転を交互に繰り返す。新しいスキンは `skins` に表示名・材質画像・番号色・金属の3色を追加する。個別の枠寸法・番号位置・装飾サイズは持たせない。共通形状を変える場合はframeImageを1か所だけ交換し、全スキンを再生成する。

```powershell
node scripts/build-card-trays.js art/ui/card-tray-v2/format.json art/samples/card-tray-v2
# Sharpが利用できる環境ではPNGも出力
node scripts/build-card-trays.js art/ui/card-tray-v2/format.json art/samples/card-tray-v2 --png
```

標準出力先はart/samples/card-tray-v2/。4テーマそれぞれ3列1行／5列1行／5列3行のSVGと、必要に応じてPNGを生成する。SVGはNode標準機能のみ。PNG生成用Sharpは通常のパッケージまたは環境変数CARD_FRAME_SHARP_MODULEで指定する。以前のv1原稿・出力は別保管し、大量の派生出力はGit管理しない。

ゲームへの組み込み・スキン選択・指示数・列数上限・セーブは変更しない。表示領域に収まらなくなった場合のゲームUI上の横スクロールは別工程とする。カード自体の可変幅化や縮小は今回行わない。

## 確認

4スキンの出力のα形状が画素単位で一致することを確認。3列／5列の左端128pxと右端の外側装飾108pxが同一で、装飾が引き伸ばされないことを検証。3行の高さ408pxも確認。材質が端の内側領域へ重なる20pxは反復柄に応じて変化し得る。4テーマの外観と同倍率のカード配置例を目視確認。
