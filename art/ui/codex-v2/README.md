# 図鑑の本素材

open-book.pngはユーザー指定の採用素材exec-a900b69e（革装丁・金具・古紙）。見開きと表紙は縦横比を維持して1200×798の基準へ配置。紙面のみCSSとCanvasで淡い明色を10%重ねる。

ページめくりはcodex-page-turn.js。紙の内端を中心線に固定し、進む時は右→左、戻る時は左→右。本文は画像に含めず、従来のシステムフォントで表示する。closed-book.pngは表紙の開閉に使用する。

closed-book.pngは2026-11-21にbuilt-in image_genで採用済み見開きを参照し再制作した革装丁の表紙。文字・紋章・付箋なし、真鍮金具・透明背景。制作指示はclosed-book-prompt.txt。
