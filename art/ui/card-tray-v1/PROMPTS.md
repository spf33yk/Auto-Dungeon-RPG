# 土台の制作プロンプト

内蔵image_gen使用。art/samples/card-bases-v1/の各テーマ画像を参照し、カードなしの単体土台を個別に制作。出力原稿はart/samples/card-tray-v1/originals/へ保存。余白を切り出して共通1024×128pxのスキン部品とし、3分割の組み立てはSVGで行う。

## classic

Use case precise-object-edit / game UI component. Reference image shows the earlier approved connected-card tray style. Produce ONE EMPTY SINGLE-ROW TRAY BASE, no cards, no Japanese text, no numbers. Very wide horizontal flat front orthographic frame, entirely visible with small transparent margin, approximately 4:1 aspect. One slim fixed number plaque on the far LEFT, blank. Then ONE continuous empty recessed card channel spanning all the rest, NOT individual card-shaped holes; no vertical slot divisions. Subtle rounded/chamfered end caps like the reference. Dark ornate fantasy UI, restrained ornament matching our connected card frames. No diamonds between number plaque and channel. Outer corner studs modest and consistent. The CENTER 70 percent must contain ONLY continuous straight top and bottom rails and very subtle uniform inset material: no diamonds, joints, symbols, text or unique motifs in center; this zone will tile horizontally for additional card columns. Left and right ends carry decoration. Single base only, no contact sheet, no mockup, no perspective, no shadows outside silhouette, transparent exterior. Theme material: antique black iron, dark charcoal inset, restrained brass gold rails
