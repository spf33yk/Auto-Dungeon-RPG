## 共通構造

1枚のスキン画像は1024×128px、外側透過。左に番号用の枠、中央にカードをはめる連続した溝、右に終端の装飾を置く。3枚固定の穴にせず、条件カードが増えても横へ伸ばせる。

横は左端128px・中央768px・右端128pxの3分割。左右の端は等倍で固定する。中央だけを通常／左右反転の順で繰り返し、繰り返し境界で同じ画素の端が接するようにする。装飾や角を引き伸ばさない。垂直方向の高さは128px固定。行は12px空けて同じモジュールを追加する。

列数C、行数Rに対し、幅は `136 + 280*C + 136`、高さは `128*R + 12*(R-1)`。3列1行は1112×128、5列1行は1672×128、5列3行は1672×408px。これは制作サンプルのレイアウト単位であり、ゲームの指示枠・列数・行数の上限を変更しない。

番号は画像へ焼き込まず、左の枠の中心(72,64)へ描く。フォントサイズ40、色はスキン定義による。番号なしの出力も `renderTray` の引数で選べる。

## スキン定義

`format.json` の `skins` にID、表示名、1024×128pxの画像パス、番号色を登録する。

|ID|名称|材質|
|---|---|---|
|classic|標準|古びた黒鉄・真鍮|
|black-iron|黒鉄|黒鉄・銀色の鋼|
|bone-parchment|骨白と羊皮紙|象牙色・羊皮紙・金具|
|obsidian-runes|黒曜石と魔法刻印|黒曜石・濃紺・紫の刻印|

全スキンで同じサイズ・切り出し位置・番号位置を使う。別のスキンは同規格の画像を追加し、IDを登録する。中央領域には固有の番号、宝石、アイコン、縦の仕切りを配置しない。左右の端に装飾を集める。中央の材質は繰り返しても目立ちにくい柄にする。

カードと土台をセットにする際は同じスキンIDへ対応づける。今回の生成コードは土台のスキン差し替えに対応し、現在のゲームUIへは接続しない。カードの別テーマ完成素材は別工程。配置例には現行のclassicカードを使用する。

## 再生成

```powershell
# 4スキン × 3列1行・5列1行・5列3行の12点をSVGで生成
node scripts/build-card-trays.js art/ui/card-tray-v1/format.json art/samples/card-tray-v1
# Sharpが利用できる環境ではPNGも生成
node scripts/build-card-trays.js art/ui/card-tray-v1/format.json art/samples/card-tray-v1 --png
# 別の定義・別の出力先
node scripts/build-card-trays.js art/ui/card-tray-v1/format.json art/samples/my-trays
```

標準出力先は `art/samples/card-tray-v1/`。Node標準機能だけで自己完結SVGを生成する。PNGにはSharpを使用し、必要に応じて環境変数 `CARD_FRAME_SHARP_MODULE` にSharp入口ファイルの絶対パスを設定する。自動インストールや外部通信はしない。

モジュールとして `renderTray(format, directory, skinId, columns, rows, showNumbers)` を呼び出すと、指定スキンと列数・行数のSVG文字列を得られる。制作出力の上限は幅・高さ32768px。ゼロ・負数・小数の列数／行数は拒否する。

## 保管と検証

原稿は内蔵image_genで制作し、プロンプトをPROMPTS.mdへ保存。大きな生成原稿、比較画像、派生SVG/PNGはGit対象外の `art/samples/card-tray-v1/` に保持する。再生成用の4画像・定義・生成スクリプトだけを小さく保持する。以前の原稿は上書きしない。

3列と5列の左右128pxが全4スキンで画素単位で一致すること、5列3行の寸法と透過、無効な入力の拒否を検証。カード入り配置例と4テーマの外観を目視確認。ドラッグ操作や実機のゲーム画面での見え方は今回の対象外。ゲームの進行・難易度・能力・既存セーブは変更なし。
