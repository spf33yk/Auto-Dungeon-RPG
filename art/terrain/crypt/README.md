# 地下墓所タイル v1

- master-64.png：64pxタイル4枚の制作原本（128×128、48色以下）。
- atlas-32.png：32pxタイル4枚の配信用アトラス（64×64、32色以下）。
- 左上／右上は床2種、左下／右下は壁2種。64px原本からnearest-neighborで生成。床のコントラストを抑え、各セルの外周色を揃えている。壁の床に接する辺は実行時に境界を補う。

原案は内蔵image_genで制作したローカルのart/samples/field-resolution-2026-10-28/source-64.png。大きい生成原案・比較画像はGit対象外。原本64pxと配信用32pxだけをGit管理する（合計32KiB以下をテスト）。PNGの一括拡大でゲームへ64px適用するのではなく、原本を編集して32px版を再生成する。

再生成：Sharp導入環境でnode scripts/build-crypt-tiles.js。第1引数にSharpのモジュールファイルパスも指定可能。Sharpは制作時だけ必要。

本編では地下墓所だけに適用。他エリアは従来の描画。キャラクターは従来の仮素材。歩行判定・マップデータは変更せず、論理座標24pxへテクスチャ32pxを描画する。
