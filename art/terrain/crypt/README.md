# 地下墓所タイル v1

現行の制作方針は32px直接編集。64px原本と以下の64→32再生成手順は旧版の保管資料として残し、今後の通常制作では使用しない。

- master-64.png：64pxタイル4枚の制作原本（128×128、48色以下）。
- atlas-32.png：32pxタイル4枚の配信用アトラス（64×64、32色以下）。
- 左上／右上は床2種、左下／右下は壁2種。64px原本からnearest-neighborで生成。周期的な石模様と共通の端画素を持たせ、同系統のどの組合せでも上下左右が接続する。単色の外周枠は付けない。scripts/lib/tile-edges.jsで配信版の端を揃える。

原案は内蔵image_genで制作したローカルのart/samples/field-resolution-2026-10-28/source-64.png。大きい生成原案・比較画像はGit対象外。原本64pxと配信用32pxだけをGit管理する（合計32KiB以下をテスト）。PNGの一括拡大でゲームへ64px適用するのではなく、原本を編集して32px版を再生成する。

再生成：Sharp導入環境でnode scripts/build-crypt-tiles.js。第1引数にSharpのモジュールファイルパスも指定可能。Sharpは制作時だけ必要。

本編の床テクスチャは地下墓所だけに適用。他エリアの床は従来色。壁はこのアトラスの下段を使わず、art/terrain/walls/の専用ドット絵で描画する（FORMAT.md参照）。下段の旧壁テクスチャは互換用に保持し、現行の探索画面では参照しない。キャラクターは従来の仮素材。歩行判定・マップデータは変更せず、論理座標24pxへテクスチャ32pxを描画する。

2026-10-28改訂容量：原本5228 bytes＋配信2869 bytes＝8097 bytes。64px・32px双方で同系統の全バリアントの対向辺が一致することをテストする。
