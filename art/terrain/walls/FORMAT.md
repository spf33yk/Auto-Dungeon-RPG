# ステージ壁マテリアル制作フォーマット

更新日：2026-11-04。現行配信はwall-autotile/v2、1マス64px。入口も同じ壁マテリアルに含め、別材質の入口を重ねない。床は独立したシームレス素材を使う。

## 本編の配信定義

crypt/tileset.jsonが現在の根拠。autotile-64.pngは256×560、4列×5行、1セル64×112。上面64px＋正面48px、rise0.75。16壁＋入口4種を収録する。足元・正面・明暗を同じ投影へ揃える。

| 項目 | 規則 |
|---|---|
| 接続 | 北1・東2・南4・西8、斜めは使わない、マップ外は壁 |
| 接続番号 | 単独0、端1/2/4/8、直線5/10、L字3/6/9/12、T字7/11/13/14、内部15 |
| 内部15 | 埋め壁として不透明に埋める。枠線・床模様・黒い穴を描かない |
| 上面・正面 | 壁上面は暗い密な構造材、正面は段差が読める明るさ。床の模様を流用しない |
| 光源 | 左上。視界外の暗色はPNGへ固定せず、実行時の共通視界で適用 |
| 接続境界 | 繋がる側に外枠を描かず、通路の縦横フレームと部屋角を連続させる |
| 前景 | 真上が歩行床なら壁を自セル内へ収める。体を隠さず透明化で解決しない |
| 入口 | 同じPNG、64×112セル、光源・rise・暗色処理。entranceWallFramesで必要位置を検出 |

壁の位置・マス判定と視界は描画サイズから独立。現行ゲーム保存はv16で、この素材規格による追加の保存移行はない。画像の縦横比を維持し、補間なしで描く。

## 旧制作工程との区別

wall-material/v1は制作入力の形式名、wall-autotile/v2は配信形式。既存のwall-material-v1.template.json・schemaとsurfaces-32.png／autotile-32.pngの工程は32px専用の互換・保管工程であり、現行配信64pxのテンプレートとしてそのまま使わない。配信側の読込先はcrypt/tileset.json。

新規ステージ素材は64px基準で制作し、既存の32px専用生成器・入力schemaの対応を確認してから使用する。今回の資料整理では生成器の64px入力対応を新規実装していない。旧原稿を新しい素材の制作入力へ流用しない。

同階層の配色・構造を変える場合も16接続・入口4種・埋め壁15・足元原点を保持し、部屋角・縦横通路・交差・視界境界を検証する。
