# 準備画面の現行UI

更新日：2026-11-04。保存v16。仕様は[SPEC](../../SPEC.md)、[整理前UIの履歴](../history/2026-11-04/docs/ui/PREPARATION_UI.md)。

## 配置

16:9・UI設計1280×720を等倍率で画面へ収め、スマホ横向きも同じ配置を使う。HUDは探索と共用。準備の専用イラスト背景と装飾枠を使い、旧「ダンジョン背景のみ」の説明を現行にしない。

上からHUD、次階ではなく現在準備中の階のヒント、所持オーグメント、探索指示／装備／スキルツリー／ステータスのタブ、編集内容、下部操作。下部は探索の予測と数値、旅の記録・あきらめる・探索を始める。

外枠の上辺はHUDの下、左右と下辺はゲーム領域端。端末全体が16:9より横長なら左右余白が生じる。上12px・下10pxの内容余白、内部パネル20px余白。外枠20px・内部枠16pxはpreparation-decor/v1の9分割・辺repeat。角と画像比率を維持し装飾はクリックを遮らない。

カード一覧は左1列の縦スクロール、中央の指示編集を広く取る。長いカード列は縮小せず横スクロール。固定の右予測パネルは置かない。

## カードと行の操作

対象・条件・アクション・スキルの4分類。所持していないカードはリストへ出さず、カード図鑑では全種類を確認できる。条件カード選択時に設定欄でHP等の値を変更する。

ドラッグまたはカード選択→光る配置先タップで配置。条件は追加口へ挿入、既存条件へ置く場合は交換。追加口はホバー・フォーカス・カード選択／ドラッグ中に開く。互換性・同名条件の重複・枠不足は検証し不正配置を拒否する。

行番号をドラッグすると土台・カード・説明を含む行全体のゴーストが掴んだ位置に追従。番号タップ→移動先行タップにも対応。上下ボタンはない。配置済みカードをリストか外す操作へ戻すと、条件は1枚、対象・実行は行ごと削除する。

行変更後も指示一覧の縦位置と各指示の横位置を保持。内容不変の再描画ではDOMを置換しない。カード列の横overscrollだけを抑制し、縦のホイール操作を親一覧へ渡す。ドラッグ時は端で自動スクロールする。

カード・土台はart/ui/preparation/FORMAT.mdとlayout.jsonの接続位置・本文領域を使う。カード間の接続先端を揃え、単純な画像引き伸ばしで隙間を埋めない。スキンは古金／黒鉄／骨白／黒曜石で端末設定へ保存。

## 予測

探索の予測ボタンの右にClear見込み、想定ターン中央値、回復余力・終了HP平均。初期8回、8／16／24回の切替、各1200ターン上限。入力変更で結果を消して計算中を表示。短い処理区間で画面に制御を戻し、古い結果は破棄する。実状態と乱数は変えない。計算失敗時は予測できないことを表示し再試行可能にする。

指示変更でも結果が同じ場合はあり得る。未配置のカードは結果に使わない。将来のボス報酬の未選択オーグメントは予測に含めない。「元に戻す」は準備開始時の指示だけを復元し、装備・成長・進行は巻き戻さない。

## 初回案内・スマホ確認

初回の準備は5項目、探索は4項目の案内。進む／戻る／完了・途中終了に対応し、オプションから再閲覧。案内中は探索停止。画面別の閲覧フラグは端末設定に保存、ゲーム保存v16へUI情報を追加しない。

667×375・844×390・932×430相当で枠・表示領域を実測し、枠左右・下辺はゲーム領域端と一致。小型サイズで装備、タップ並べ替え、探索・戦闘・Clear・次階準備を確認。実機のタッチドラッグ・Safari・回転・全画面は未確認。[検証記録](../../IMPLEMENTATION_NOTES.md)を参照。


## 種類別カラーと常設最終行（2026-11-04）

ビルド工房・組み合わせチップを削除。ターゲット＝青、条件＝金、アクション＝橙、スキル＝紫を画像部分・文字・一覧タブに共通適用する。全4スキンで画像比率と接続形状を維持する。

編集行の後に操作できない「自分 → 階段を上る」を常設。横スクロールで列を確認できるが、ドラッグ・置換・削除等はできない。行数・カード枚数上限から除外し、編集行0でも表示する。読み取り専用表示にも含める。

準備開始時からの予測差分とClear・死亡時の実績要約は撤去する。枠外は暗い単色、装飾境界まで背景を描画。HUDの下に上辺、左右・下辺はゲーム画面端の位置を保つ。

2026-11-04：カードの種類別カラーを低彩度に調整。準備の内側は維持し、外側だけ暗い単色にする。装飾下の内側背景はフレームまで描画する。詳細はSPEC.mdを参照。

2026-11-04 サイズ復元：準備画面本体の20px境界を撤去し、追加前の広い内容領域へ復元。装飾フレームは独立レイヤーのまま、上辺はHUD下・左右下辺は画面端。内側の背景は全面に描画し、外側のダンジョンと影だけ非表示とする。カード配色・操作・保存は変更しない。

2026-11-04 カード表示の統一：カード本体4種類は共通の基本素材を使用し、スキン切替では土台・周辺装飾だけ変更する。種類別カラーは固定。行の文章冒頭の「使用枚数 / 上限枚数 ·」を非表示とする（枚数上限の判定は維持）。大外フレーム外側の遮蔽は維持し、カードリストと探索指示のパネル背景・内側の影は透明化する。寸法・操作・取得条件・保存v16に変更なし。

2026-11-04 外周の漏れ修正：大外装飾の透明な外縁から内側背景が漏れるため、準備本体を四辺5pxだけクリップする。独立した装飾はクリップせず、背景の見える範囲だけを制限する。内容のレイアウト・寸法、内側パネルの透過、カード色、保存は変更しない。

2026-11-04 実績表示の撤去・土台ドラッグ：Clear・死亡画面のATK補正、ビルドの活躍、与被ダメージ集計、指示実行回数の表示を削除する。内部集計と旧保存の互換データは維持するが表示しない。探索指示の編集可能な土台全体を行ドラッグ開始領域に追加。カード上はカード単体の移動、条件追加口は従来操作を優先。常設最終行は移動不可。準備中のみ編集でき、スクロール保持とタップ操作を維持する。保存v16への影響なし。


## 指示保存と選択宝箱の追加

現行はカード33種、能動スキル6種。捨て身の斬撃（EPIC）・円環の斬撃（LEGENDARY）・骨の守り（EPIC）・静寂の構え（EPIC）を追加。各階1回の取得・配置型。行ごとの有効／無効と端末内10件のプリセット、探索中の実行行番号表示に対応。宝箱は同種類・同レアリティから最大3候補の1枚選択制。値・取得条件・保存・予測方針はSPEC.md第13節を正とする。


## 5職業のアイコンとセット表示

オーグメントは専用絵30種、職業アイコン5種。準備のオーグメント欄は上段を横スクロール、下段に成立テーマのセット帯を表示する。スキルカードはリスト・配置済みの両方に職業アイコン、成立中はSET文字と発光を付け、タイトル説明で強化内容を確認できる。無効行では解除される。選択画面は選ぶと成立するセットを予告し、図鑑でもテーマ・成立状態を示す。

絵は正方形原本をcontain表示し、スキンやカード枠の縦横比は変えない。長い説明はフレーム内でスクロールし、図鑑の最小カード幅を240pxとする。大外フレームの遮蔽、内側パネルの透過、土台ドラッグ、プリセットは維持する。今回の実画面・実機確認の未実施はIMPLEMENTATION_NOTESへ記録。
