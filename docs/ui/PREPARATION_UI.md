# 準備画面の連結カードUI（実装済み）

2026-10-29。標準テーマのカード4種類と土台3部品をゲームへ適用。別テーマの原稿・フォーマットは保管し、ゲーム内のスキン切替は今回の対象に含めない。

## 表示

従来の左リスト・中央指示・右予測を、左210pxのカードリストと残り幅の指示編集へ変更する。カードリストは1列。カテゴリ切替はターゲット／条件／アクション／スキル。配置列はターゲット→条件→アクションまたはスキル。内部の判定優先順や全条件ANDのルールは変更しない。

素材は等倍率の拡大・縮小のみ。カードは幅260×高さ約65.63論理px（元の515:130を維持）、隣のカードとの重なり22px。リスト内も元比率のまま幅に合わせる。土台の高さ96px、左端96px・右端48px、中央の反復画像576×96pxはすべて元PNGの75%倍率。長いカード列は行ごとに横スクロールし、カードを変形・折り返ししない。指示行は縦スクロール。PCとスマホ横持ちで同じ1280×720の論理レイアウトを画面へ合わせる既存方式を維持する。

カード見出し・アイコンは承認された素材をそのまま使用し、実際の内容と条件値はHTMLで重ねる。将来の多言語対応や別テーマ完成版では見出しも文字なし素材へ分離する余地があるが、現在の条件値は画像へ焼き込まない。

本文と行番号の位置はart/ui/preparation/layout.jsonで定義する。本文欄は515×130pxの素材上の(x=52,y=64,width=404,height=40)で、リストと指示カードの両方をこの欄の縦横中央に配置する。ボタンのpaddingで位置を決めない。番号は土台上の中心(54,48)へ配置。長い本文は枠内で省略し、配置済みカードのtitleとaria-labelに全文を残す。update-assets.jsが定義をCSS変数としてindex.htmlへ埋め込み、表示倍率が変わっても素材に追従させる。

## 操作

- 配置済み条件をタップすると上部に設定欄を表示。数値のある条件はカード定義の最小／最大／刻みで入力し、変更後に指示へ反映する。数値のない条件は説明のみ。
- リストの条件を選択した場合も同じ設定欄を表示。入力値は次に配置する同名条件へ適用する。この配置前の値は一時的なUI状態で、セーブしない。
- 選択すると配置可能な溝を明るい破線で強調、不可の場所は暗くする。ドラッグ中に有効な配置先へ重なると実線へ変更する。
- 既存のドラッグと「選択→配置先タップ」の両方を維持。条件の入れ替え・行間の移動・対象／実行カードの交換は既存の組み合わせ検証を通し、不可の操作でデータを変えない。
- 行の移動は番号のドラッグで行う。番号を選択して移動先の行をタップする方法も利用できる。↑↓ボタンと操作メニューは配置しない。
- 条件カードまたは行を「ここへ移動して外す」へドラッグして削除する。選択後に同じボタンをタップしても削除できる。ターゲット・実行カード・未配置カードは削除できない。
- 横スクロール領域の左右端、リストと行一覧の上下端へドラッグした場合は表示を自動スクロールする。ドラッグ開始時には条件設定欄を開閉せず、配置先がずれることを防ぐ。
- 編集は準備中だけ。探索中とひとやすみ中は従来どおり閲覧のみ。

## 探索の予測

下部の「旅の記録」の左に「探索の予測」ボタンを追加。固定の右パネルをなくし、ボタンからダイアログで開く。8／16／24回、再予測、参考値の注意、指示を元に戻す機能は維持する。編集領域にも「元に戻す」を残す。

予測はダイアログを開いたときだけ実行。閉じた場合や準備フェイズを離れた場合は計算をキャンセルする。「元に戻す」はその階の準備開始時に記録した指示へ戻す。装備・能力や進行は戻さない。

## 素材・保存・配信

art/ui/preparation/に515×130pxのカード4点と、左128×128・中央768×128・右64×128pxの土台3点を保存。合計230,440bytes（約225KiB）。元のデザインはcard-frame/v1とcard-tray/v3へ保持。scripts/build-card-frames.jsはX/Y別の倍率を廃止し、1つの倍率で枠内へ収めて余白を残す。scripts/build-preparation-assets.jsは追跡対象の部品と定義から再生成できる。Sharpが必要。

update-assets.jsが7点の内容ハッシュをindex.htmlのpreparation-assetsスタイルへ登録し、JS/CSSのハッシュも更新する。比較画像や大きな生成原稿は配信しない。

セーブはv13のまま。既存の指示行・条件値・取得条件・行数／カード数の上限とコストは変更しない。変更した指示は従来の自動保存へ反映する。旧セーブの追加移行は不要。
