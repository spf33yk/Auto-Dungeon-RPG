# 準備画面

現行仕様は[SPEC](../../SPEC.md)第8・11節。保存v16。

## 配置

共用HUDの下から、階のヒント→所持オーグメント→探索指示／装備／ステータスの3タブ→編集領域→下部操作を配置する。専用背景を使用。外枠上辺はHUD下、左右・下辺は16:9ゲーム領域端。大外だけ外側を遮蔽し、内部パネル外は透過。装飾は角固定・辺反復、背景だけ四辺5pxクリップ。

カードリスト1列、中央指示を広く、長い指示は横スクロール。スキル一覧は5テーマごとにまとめて見出しアイコンを表示。タブ列を薄くし編集2行が見える高さを確保。土台とカードは等倍率0.7、小型画面高500px以下は0.58。種類別の低彩度色は4スキン共通。カード文字・レアリティは土台より手前。

## 編集

準備中のみドラッグ／タップに対応。カードは単体、番号・土台余白は行を掴む。返却先はカードリストに統一し、返却中にハイライト。条件は1枚、それ以外は行全体を外す。条件挿入口はホバー・条件カードの選択／ドラッグで展開。通常カードのドラッグでは条件を強調しない。一覧からのドラッグで指示を自動スクロールさせない。

条件の数値はカード内で入力しEnter／フォーカス移動で確定。周囲の枠からドラッグする。「有効／無効」で一時除外。行移動後も縦・行ごとの横位置を保持し、同一内容ではDOMを再生成しない。

編集上限は2〜10行、1行4〜6枚。最終行は自分→階段を上るで固定し上限を消費しない。「行追加」、複数条件、視界は記憶の欠片で購入。ステータス能力の購入UIはない。プリセットは最大10件。新着カードと種類タブにNEWを付け、出発成功時に解除する。

## オーグメント・予測

枠・アイコンの周囲と文字領域は透過。所持列は枠全体を確保して横スクロール。ホバー専用ウィンドウで現在の効果・星・同テーマ配置の説明を表示。0種でも☆☆☆、1／3／6種で★1／2／3。同テーマのスキルカードを発光させSET文字は付けない。

下部に探索の予測とClear率・成功ターン中央値・終了HP平均、準備開始時との差、旅の記録・あきらめる・探索を始める。予測は保証値ではない。ビルド工房と探索後の活躍集計UIは設けない。

## 宝箱・案内

宝箱ダイアログは最大1040px／画面94%。種類選択を上、その下へ所持オーグメントを折返し表示。種類は一度だけ選択し、カード候補は縦1列。取得後は探索を自動再開する。準備チュートリアル7手順は実際の操作で進み、オプションから再閲覧できる。

探索の操作チュートリアルはオーグメント選択ダイアログ内の案内のみ。準備の7手順は変更しない。
