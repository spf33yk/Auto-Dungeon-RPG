# 準備画面の現行UI

更新日：2026-11-04。保存v16。仕様は[SPEC](../../SPEC.md)、[整理前UIの履歴](../history/2026-11-04/docs/ui/PREPARATION_UI.md)。

## 配置

16:9・UI設計1280×720を等倍率で画面へ収め、スマホ横向きも同じ配置を使う。HUDは探索と共用。準備の専用イラスト背景と装飾枠を使い、旧「ダンジョン背景のみ」の説明を現行にしない。

上からHUD、次階ではなく現在準備中の階のヒント、所持オーグメント、探索指示／装備／スキルツリー／ステータスのタブ、編集内容、下部操作。下部は探索の予測と数値、旅の記録・あきらめる・探索を始める。

外枠の上辺はHUDの下、左右と下辺はゲーム領域端。端末全体が16:9より横長なら左右余白が生じる。上12px・下10pxの内容余白、内部パネル20px余白。外枠20px・内部枠16pxはpreparation-decor/v1の9分割・辺repeat。角と画像比率を維持し装飾はクリックを遮らない。

カード一覧は左1列の縦スクロール、中央の指示編集を広く取る。長いカード列は縮小せず横スクロール。固定の右予測パネルは置かない。

## カードと行の操作

対象・条件・アクション・スキルの4分類。所持していないカードはリストへ出さず、カード図鑑では全種類を確認できる。条件カード選択時に設定欄でHP等の値を変更する。

ドラッグまたはカード選択→光る配置先タップで配置。条件は追加口へ挿入、既存条件へ置く場合は交換。追加口はホバー・フォーカス・カード選択／ドラッグ中に開く。互換性・同名条件の重複・枠不足は検証し不正配置を拒否する。

行番号をドラッグすると土台・カード・説明を含む行全体のゴーストが掴んだ位置に追従。番号タップ→移動先行タップにも対応。上下ボタンはない。配置済みカードをリストか外す操作へ戻すと、条件は1枚、対象・実行は行ごと削除する。

行変更後も指示一覧の縦位置と各指示の横位置を保持。内容不変の再描画ではDOMを置換しない。カード列の横overscrollだけを抑制し、縦のホイール操作を親一覧へ渡す。ドラッグ時は端で自動スクロールする。

カード・土台はart/ui/preparation/FORMAT.mdとlayout.jsonの接続位置・本文領域を使う。カード間の接続先端を揃え、単純な画像引き伸ばしで隙間を埋めない。スキンは古金／黒鉄／骨白／黒曜石で端末設定へ保存。

## 予測

探索の予測ボタンの右にClear見込み、想定ターン中央値、回復余力・終了HP平均。初期8回、8／16／24回の切替、各1200ターン上限。入力変更で結果を消して計算中を表示。短い処理区間で画面に制御を戻し、古い結果は破棄する。実状態と乱数は変えない。計算失敗時は予測できないことを表示し再試行可能にする。

指示変更でも結果が同じ場合はあり得る。未配置のカードは結果に使わない。将来のボス報酬の未選択オーグメントは予測に含めない。「元に戻す」は準備開始時の指示だけを復元し、装備・成長・進行は巻き戻さない。

## 初回案内・スマホ確認

初回の準備は5項目、探索は4項目の案内。進む／戻る／完了・途中終了に対応し、オプションから再閲覧。案内中は探索停止。画面別の閲覧フラグは端末設定に保存、ゲーム保存v16へUI情報を追加しない。

667×375・844×390・932×430相当で枠・表示領域を実測し、枠左右・下辺はゲーム領域端と一致。小型サイズで装備、タップ並べ替え、探索・戦闘・Clear・次階準備を確認。実機のタッチドラッグ・Safari・回転・全画面は未確認。[検証記録](../../IMPLEMENTATION_NOTES.md)を参照。
