# キャラクターの残課題

現在の主人公はmukuro-march64-v1の4方向4姿勢・800ms足踏みを使用する。攻撃は接地姿勢の踏み込み・斬撃、死亡はフェード。足踏み制作が中止中という扱いにはしない。

専用の振り上げ→振り下ろし、被弾のけぞり、体が崩れる死亡、敵の方向別歩行・専用攻撃コマと倅の全動作は後続課題。制作は新しい明示依頼から始め、採用前に動作サンプルで確認する。詳細の未決定モーションを確定仕様とみなさない。

[素材フォーマット](FORMAT.md)と[中止素材の扱い](PROTOTYPE_RESET.md)に従う。

敵の攻撃は静止素材のため・踏み込み・復帰と攻撃マークを実装済み。専用の攻撃コマを完成したものとは扱わない。仕様は[敵攻撃](ENEMY_ATTACK.md)。
