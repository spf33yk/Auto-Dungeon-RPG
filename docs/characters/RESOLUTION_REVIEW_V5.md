# 骸の32px／64px比較 v5

> **2026-11-01：旧試作は削除済み・制作中止。** 本文の旧試作・質問回答・プロンプトは履歴であり、次回の作画条件として再利用しない。本編使用中のmukuro-v1のみ保持。最新の決定は [試作リセット](PROTOTYPE_RESET.md) を参照。

目的：正面の顔の崩れ、横向きの足踏み、背面の斜め斬撃を見直して、解像度による判読性を比較する。ユーザーの「32bit／64bit」は32×32px／64×64pxとして扱う。色深度の変更ではない。今回の64pxは比較用であり、ゲームの32px統一方針を変更しない。

- 同一生成原稿を32pxと64pxへ別々に縮小する。64pxは32px画像の拡大ではない。同じ大きさで最近傍表示して比較する。
- 正面は2つの眼窩、鼻腔、頬骨、顎を分離する。頭身と赤いマントは保つ。
- 足踏みは右膝と右足を高く上げる→左膝と左足を高く上げる。支持足は接地。横向きの奥の脚も輪郭から出して、同じ脚を上げ続ける絵にしない。各300msは確認用仮値。
- 攻撃は静止→振り上げ→斜め中間→振り下ろし→静止（400/280/100/180/400ms、確認用仮値）。背面は最新のユーザー指示に合わせ画面右上→右斜め中間→右下とする。左側を指定した途中案は撤回。全コマで手・柄・剣をつなぎ、剣を手放さない。
- 行は下・左・右・上。左を反転して右を作成するため、右向きの攻撃軌道も反転する。背面は画面右側。右向きは反転許可を維持した比較案であり、全方向の攻撃を画面右側へ統一するものではない。
- 6列（静止・右足上げ・左足上げ・振り上げ・斜め中間・振り下ろし）×4行。PNGは32px版192×128、64px版384×256。アンカーは[16,29]または[32,58]。
- 共通倍率で整形し、縮小後アルファを0/255へ限定、32pxは32色、64pxは48色に量子化する。
