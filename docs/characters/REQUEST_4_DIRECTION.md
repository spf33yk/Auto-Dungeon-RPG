# 依頼：2Dローグライクゲームのキャラクター4方向アニメーション制御システムの実装

仕様書 `wall-autotile/v1` のマップシステム上で動作する、プレイヤーおよびモンスター用の「上下左右4方向・2コマ歩行」のアニメーション制御クラス（またはモジュール）を実装してください。

### 1. キャラクターのグラフィック仕様
キャラクターの素材（スプライトシート）は、1マス32x32px（または任意サイズ）のグリッドで以下のように統一して配置されています。
* **縦4行（方向 ID）**
  - `0`: 下（South / 前面）
  - `1`: 左（West）
  - `2`: 右（East）
  - `3`: 上（North / 背面）
* **横3列（状態・アニメーションフレーム）**
  - `0`: 歩行/待機フレーム 1
  - `1`: 歩行/待機フレーム 2
  - `2`: 攻撃モーション（1コマ）

### 2. 要求する機能・要件
1. **状態管理（状態と方向）**
   - キャラクターは常に「位置(x, y)」「現在の方向（0:下, 1:左, 2:右, 3:上）」「現在の状態（待機、移動中、攻撃中）」を保持してください。
2. **方向変更ロジック**
   - 移動または攻撃の入力があった際、対象の座標へのベクトルの向きに応じて、自動的に方向ID（0〜3）を更新する関数を作ってください（斜め入力があった場合は、直前の方向を維持するか、上下左右のいずれか近い方に安全に丸めてください）。
3. **アニメーション制御**
   - **足踏み/移動時:** フレーム `0` と `1` を一定時間（またはターン進捗）ごとに交互にループさせてください。
   - **攻撃時:** 一瞬だけフレーム `2` に切り替わり、攻撃モーション終了後に自動で元の状態（待機フレーム）に戻るトリガー関数を作ってください。
4. **描画座標のバインド**
   - キャラクターの描画位置（Y座標）は、マップの壁仕様と同様に足元が正しくソートされるよう、グリッド座標から適切なピクセル座標へ変換して描画ロジックへ渡せるようにしてください。

### 3. 出力コードのイメージ
使用している環境（純粋なJavaScript Canvas / Phaser / PixiJSなど）に適した、再利用性の高いクラス構造（例: `class Character`）で出力してください。スプライトシートから `(dirId, frameId)` を使って特定の切り抜き領域（x, y, w, h）を計算するヘルパー関数も含めてください。
