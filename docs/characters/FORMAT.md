# キャラクター素材・描画フォーマット

## 本編主人公

採用先はart/characters/mukuro-march64-v1/sprites.json。形式character-minimal-4dir/v1、身体64px基準・保存セル128px・4列4行512×512。方向は下・左・右・上、姿勢は接地A／足上げA／接地B／足上げB。原点[64,96]、displayScale1.71875。animation.cycleDurationsMs=[120,280,120,280]、周期800ms。詳しくは[MARCH64_INTEGRATION](MARCH64_INTEGRATION.md)。

待機・移動は連続描画時計を共用し、移動開始ごとに周期を戻さない。攻撃・死亡・reduced-motionは接地0を使用し、踏み込み・斬撃・フェードは描画処理で適用。足元基準でマップと整列する。マス座標・身体・保存セル・画面倍率を区別する。

## 互換形式

character-animation.jsはcharacter-4dir/v1の方向4行・歩行2列＋攻撃1列などの読込互換を維持する。schema／templateは互換形式の検証用であり、新規作画の32px指定ではない。既存ローダーの形式と本編採用素材を混同しない。

## 制作

新規素材は1マス64px基準。縦横比を保持した等倍率で拡縮し、ピクセルは補間しない。採用済み主人公を基準に修正する。中止済み試作・旧プロンプト・キャッシュ画像を制作入力へ流用しない。追加モーションは新しい明示依頼から開始する。
