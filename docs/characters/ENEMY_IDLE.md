# 敵の共通2px待機

敵の素材はart/enemies/v2/atlas-64.pngを維持。enemy-idle.jsのENEMY_IDLEはperiodMs=1400、amplitudePx=2、footRows=10。新しい絵・追加コマ・縦横別の伸縮を使わない。

起動時にアトラスの各64pxセルから不透明部分の最下端を調べ、その手前10pxを固定足元とする。下側を元の位置へ描き、上半身を一枚のまま0/1/2px下へ移動する。下へ沈むときだけ足元側と2pxまで重なる。上半身と下半身の各描画は同じ等倍率で、足元原点・影・マス・HPラベルは動かさない。

敵ごとのIDと初回の位置から1400ms内の位相を決め、WeakMapへ保持。敵が移動しても位相を変えず、一斉に同じ姿勢にならないようにする。移動／保存の状態へは追加しない。idleClockで待機と休止中の呼吸を進め、ヒットストップ・非表示では止める。

攻撃姿勢が有効な間、実被弾から400ms、撃破用の描画、reduced-motionでは0pxへ戻す。元の攻撃・ノックバック・白化を優先する。身体のスキル中心へだけ屈伸分のYを足して、足元影とHPバーは移動しない。

全登録フレームの足元境界と等倍率を自動検査する。新種や空中型・大型の導入時は分割位置と足元部位が適切かを個別に確認し、必要なら共通設定からの例外を検討する。現在の全種の実機目視・モバイル性能まで確認済みとは扱わない。
