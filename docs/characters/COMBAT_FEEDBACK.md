# 戦闘接触の描画仕様

本書はSPECの「戦闘の接触演出」を実装へ対応づける。1マス64px。キャラ画像の身体寸法・128px保存セル・アンカー・等倍率を維持する。

| モジュール | 責務 |
|---|---|
| game-engine.js | damageEventsに表示専用source・impact・skillIdを付記。戦闘結果は従来どおり即時確定 |
| combat-feedback.js | 接触予約、姿勢停止とFX時計、反動、敵白化の可否、揺れ、6粒子、星、軌跡、撃破時の描画参照 |
| damage-view.js | 接触後850msの数値表示、短い上昇と保持、フェード、連続着弾時の積層 |
| app.js | tick前の個体参照とイベントを結び、身体／FXの変換、白版アトラス、UI固定、画面状態に応じた破棄 |
| ui-settings.js | screenShakeを端末へ保存。初期ON、音量設定を維持 |

## 時計と接触

姿勢はactorTime、FXはtime（appのheroClock）を使用。主人公の通常近接は攻撃姿勢35%、敵は45%で接触。1tickの先頭の非罠ダメージだけが停止を予約する。0.5/1倍50ms、2倍1000/60ms、4倍0ms。区間の途中で接触した場合も、その正確な時刻から停止区間だけactorTimeを進めない。操作・ターン・HP判定は止めない。白化・火花・粒子は停止中もtimeで進む。休止ではtimeとactorTimeを両方凍結し、待機足踏み専用のidleClockだけ継続する。ヒットストップ中はidleClockへactorTime差分を渡して足踏みも止める。

スキルのダメージは即時接触とし、全11種の攻撃専用8コマFXと共通命中演出を併用する。骸の攻撃姿勢も再生。frenzy／blood-cut／sweep／life-burn／life-bet／all-inは姿勢開始から22〜73%の剣の弧を追加する。palm／one-thought／bite／shield-bash／coin-strikeは専用の掌・気・牙・盾・硬貨のFXを維持し、剣の弧を追加しない。命中のない攻撃スキルも使用者の姿勢は動かすが、命中反応は作らない。回復・補助スキルは攻撃姿勢を出さない。罠は即時数字だけ。0ダメージには接触FXを追加しないが、既存の敵攻撃姿勢は維持する。

## 寸法と重複

敵の白化は1000/30ms、アトラスのアルファを維持。骸を白化しない。反動6pxは攻撃元から離れる正規化ベクトルへ適用し、停止後8000/60msでease-out、後の200msで戻る。同時反動もベクトル長6pxで制限。反動の経過もactorTimeへ合わせ、他の接触で停止した際も両者の反動を止める。セル・経路・衝突は変えない。

揺れは最大1.5px、10000/60msで二乗減衰。複数命中は加算せず最後の有効な接触を使う。世界の描画へだけ加え、ラベル／HP／数字の前に打ち消す。UIは揺らさない。

火花は接触側（対象の身体中心から攻撃元へ0.18マス）に半径6pxの星を4000/60ms表示する。6粒子は360ms、低彩度の灰／骨／スライム色。描画用の整数計算だけを使用し、ゲーム乱数に触れない。近接弧は姿勢22〜73%、半径32px・線幅2pxの象牙色で既存slashへ重ねる。すべてworldTileに比例して等倍率表示する。

同じtick・対象・攻撃元の追撃は1つのFXへまとめるが、ダメージ数字は各打撃を維持。キューは最大64件。撃破後は個体参照を描画だけに残し、接触から50ms後に300msで消す。死体の衝突や行動は発生しない。

## 可読性と設定

敵の頭上に淡金、骸の右肩上に淡赤とマイナス記号で表示。黒縁付きの太字セリフ体25px、会心は30pxと「!」。100msで7px上昇し、450ms保持して300msで消える。連続被弾では古い数字を22pxずつ最大3段上へ送る。

休止・モーダル・非表示で戦闘演出の描画時計を止める。足踏みだけは非表示を除いて独立時計で継続する。準備・新しい旅・フロア変更でキューを破棄。保存v16のままで演出キューを保存せず、damageEventsもロード時に空へ戻す。screenShake=falseなら揺れだけOFF。prefers-reduced-motionなら停止・反動・白化・揺れ・追加FX・数字の跳ねを抑える。数字は静止フェードで結果を伝える。
