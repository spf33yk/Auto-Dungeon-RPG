# 主人公足踏み版の本編仕様

承認済みr12を本編に使用する。新規の生成や試作への差し戻しは行わず、今後の修正も採用版を起点にする。

採用先はart/characters/mukuro-march64-v1/。4列4行512×512、保存セル128px、身体64px基準、原点[64,96]、displayScale1.71875。下・左・右・上を独立に格納し、本編で左右反転しない。16原画とハッシュを保存し、将来の修正はこの採用版を起点とする。

character-minimal-4dir/v1に4列とanimation.cycleDurationsMsを追加。順に120/280/120/280ms、800msで接地A→足上げA→接地B→足上げBを再生。移動中も待機中も同じ速さで、ゲームの0.5/1/2/4倍速は見た目の足踏み周期を変えない。独立したidleClockをcycleElapsedとして渡し、移動・待機の切替で後半の脚が再生されなくなることを防ぐ。休止・ハウス通知・ダイアログ中も足踏みだけ継続する。通常動作中のヒットストップはactorTime差分で足踏みへ反映し、非表示時は止める。移動・攻撃・FXは休止中に進めない。

攻撃は接地0を使用して、従来の方向別踏み込み・斬撃を表示。攻撃判定・攻撃時間・ダメージ・AIは変更しない。死亡とreduced-motionは接地0、死亡の780msフェードも維持。肖像は正面0の従来範囲。セーブv16・操作・難易度・ワールドのマス寸法に変更なし。旧セーブの移行は不要。旧3列屈伸・旧character-4dirも互換対応を保持する。
