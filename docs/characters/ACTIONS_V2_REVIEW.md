## 今回の依頼と追加指摘

- 攻撃：剣を上から振り下ろす。振り上げる→振り下ろす。
- 被攻撃：のけぞるアニメーションを追加。
- 移動：静止→右足前・左手前→左足前・右手前→静止。
- 32pxでエイリアンに見えない人の骸骨へ修正。赤いマントと暗い雰囲気を維持。
- 剣を持っているように見えること。拳・柄・鍔・刃を連続させる。
- 背面を省略せず、下・左・右・上の4方向を必須にする。背面では右手と剣をマントの外へ出す。
- 素材を先にGIFで確認し、採用後にゲームへ反映する。

## 32pxでの見た目の基準

巨大な滑らかな卵型の頭と大きい黒目を避ける。適度な頭蓋骨、角のある眼窩、三角の鼻腔、頬骨、細い顎と短い歯列で人の骨と分かるようにする。肋骨・骨盤・関節を読める太さにする。32px実寸と拡大の両方で確認する。

剣は腕→手首→閉じた骨の拳→茶色い柄→鍔→灰色の刃をつなぐ。刃だけを手の横に浮かせない。握りの小さい部分ほど色差を確保する。骨色の拳で柄を覆い、柄と鍔を少なくとも判別できることをGIF確認項目とする。

背面は顔を描かず、後頭部・外套・右腕・握った剣を描く。マントで膝・足・握りを全て隠さない。右向きも専用行とし、確認用GIFには4方向を同時表示する。

## 採用予定のフレーム構成

32×32px、6列×4行、全体192×128px、方向順は下・左・右・上。足元はy29、最終可視行28、透明余白は2px。現行3列のv1へ6列PNGをそのまま読み込ませない。

| 列 | 役割 | 骸のポーズ |
|---|---|---|
| 0 | idle | 静止、剣を握って低く構える |
| 1 | step-a | 右足と左手を前へ、逆側は後ろ |
| 2 | step-b | 左足と右手を前へ、逆側は後ろ |
| 3 | attack-windup | 剣を頭上へ振り上げ、全刃をセル内に収める |
| 4 | attack-strike | 手と剣を下へ振り下ろした終点。刃先は柄より下 |
| 5 | hurt | 足元を残して胸と頭を後方へ反らす |

敵や倅にも同じ役割のコマを用意する。敵に剣がない場合は列3を攻撃準備、列4を爪・体当たり等の攻撃姿勢として扱う。待機は1コマ静止へ変更する設計。新規のhurt状態、攻撃2段階、移動0→1→2→0の実行時制御は採用後に実装する。

## 生成回数を抑える手順

1. 4方向の静止姿で、頭蓋骨・赤マント・拳の握り・背面の剣を確認する。背面を後回しにしない。
2. ポーズガイドで左右の足と反対の腕、振り上げ／振り下ろし、のけぞりを明示する。
3. 問題があるコマだけを修正し、全体を毎回生成し直さない。
4. 透明性は見た目の背景色ではなくα値で検査する。RGBに下地が残ってもα0なら透明であり、不要な再生成を避ける。
5. 32px原稿から歩行・攻撃・被弾を別々のGIFへ出力し、実装前に確認する。
