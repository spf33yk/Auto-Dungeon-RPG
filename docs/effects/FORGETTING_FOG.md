# 忘却の霧・標準強度

fog-effect.jsのFOG_EFFECTが共通設定。periodMs=6400、frameMs=50、width=160、height=90、dust=6。忘却の霧の探索・死亡・Clearマップへ適用し、準備・タイトルには描かない。霧罠の短期状態は適用対象を増やさない。

固定ハッシュから補間したノイズ、青灰色の二層の煙、柔らかな正弦帯、6粒の薄い塵を合成。ノイズと正弦位相が6400msで繰り返す。主人公の身体中心をカメラ変換した位置に密度低下マスクを置く。上限68%の密度低下。世界の照明を描いた後、専用スキルFX・敵ラベル・ダメージ数字より前へ描く。UI・ミニマップ・実際の視界や敵検出を変更しない。

1枚の小さい透過canvasを再利用し、50msの時刻区間と中心位置に変更があるときだけRGBAを更新。描画は全体を同じ縦横比でマップへ拡大する。ゲームの乱数・進行へ依存しない。休止中もidleClockで流れ、非表示では時計を止める。reduced-motionでは位相0を再利用して塵を描かない。

配信画像の追加は不要。画質・強度を調整する場合は小レイヤーの寸法／更新上限と色・密度式を変更し、主人公・宝箱・敵・ラベルの可読性とスマホ負荷を確認する。
