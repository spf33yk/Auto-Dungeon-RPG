# 5テーマの構成

探索家・修行僧・狂戦士・守護者・勝負師。各テーマはオーグメント／スキルともNORMAL3・EPIC2・LEGENDARY1、各30種。themeIdが正式な分類。

初期の未所持プールは各テーマ重み265、合計1325で対称。3択は未所持から重み付き復元なし抽選であり、各テーマが必ず出るわけではない。同テーマスキルを1／3／6種類有効配置すると、オーグメントが★1／2／3へ成長する（全30種の個別表・仮採用）。0種も☆☆☆。重複スキルは数えない。

[効果・星別性能](BUILD_THEMES_V2.md)と[通し検証](../verification/CURRENT_BALANCE.md)を参照。種類数が同じでも強さ・入手機会・勝率が等しいとは限らない。今回の通し検証は特定の自動方針による結果であり、テーマ別の無作為比較実験ではない。
