# 実行者指定カード v1（現行）

2026-11-07。構成は「ターゲット＋条件＋アクション／スキル」を維持する。ターゲットは実行者を指す。条件名には主語を追加しない。

## 決定事項

- ターゲットは「自分」「敵」の2種類、いずれも最初から所持。宝箱からは出さない。仲間の指定は将来の拡張候補で、今回は未実装。
- 自分は骸。敵は現在の視界内で最も近い通常敵1体。ボスは除外し、同距離ならY→X順。最も近い敵が条件を満たさなくても、遠い別の敵へ差し替えない。
- HP条件は選んだ実行者の現在HP／最大HPを参照。「敵＋HP50%以下＋小さな祈り」は敵自身を回復し、「自分＋HP50%以下＋小さな祈り」は骸を回復する。
- 攻撃する場合、自分は敵へ、操作する敵は骸へ向かう。同士討ちは行わない。敵は自分の攻撃力・防御力・最大HPを使い、骸の装備・オーグメントを引き継がない。
- 有効行を上から判定する。敵への指示が成立すると骸の行動枠を1ターン使う。選んだ敵の通常行動周期は維持し、行動可能なターンだけ指示を実行する。その敵の通常AIを同ターンに二重実行しない。他の敵は通常どおり動く。
- 指示は毎ターン、現在の視界内で選び直す。視界外へ出た敵や条件を満たさなくなった敵は通常AIへ戻る。敵の探索で骸の発見地形や品物記録は公開しない。

## 行動の役割

「全ての部屋を探索する」は未入室の部屋を優先し、全てへ入ったら完了。「全てのマスを探索する」は未踏の到達可能な床を歩く。部屋の隅まで歩く必要があるかが違う。骸は発見済み地形と未探索境界から経路を選び、未発見の部屋への近道を透視しない。敵は通常の敵経路探索と同様に地形を使い、指示中の入室／歩行履歴を保持する。操作開始前の通常歩行は数えない。

敵が実行できるアクションは、攻撃する・相手から離れる・全ての部屋を探索する・全てのマスを探索する。宝箱・品物・手紙の取得、階段Clear、骸の戦術・罠回避方針は自分専用。ターゲットを変更した時は対応する行動を維持し、敵に非対応の行動なら「攻撃する」へ置換する。

## スキルとオーグメント

全30スキルは所持だけでは発動せず、有効な指示と条件成立が必要。発動は1ターンで各階1回。使用回数は骸と敵操作で共有し、実行者が変わっても再使用できない。発動後の持続・次の一撃・防御回数等は技能説明どおり残る。オーグメントは所持で自動適用し、指示への配置は不要。旧パッシブ3種は互換データとして残すがスキル選択・デバッグ報酬一覧には公開しない。

敵に使えるのは25スキル。下記5種は実行先の機能がないため配置不可とする。骸では従来どおり使える。

|スキル|敵で使えない理由|
|---|---|
|罠抜け|敵は罠を作動させない|
|道標|骸の地図を公開する技|
|運試し|骸の記憶の欠片を消費する技|
|宝探しの賭け|骸の回収品を扱う技|
|帰路の印|骸のフロア帰還用の技|

HP消費・回復・自己強化は実行者に適用し、攻撃はその実行者の相手へ向かう。敵の防御・自己強化はその後の通常AI時にも説明どおり有効。敵の技能名は敵の頭上に表示する。セットの星は同テーマの有効配置スキル種類数を数え、敵向けの配置も含めるが、強化されるオーグメントは骸のもの。

## 条件の参照と制限

HP上下・半分以下は実行者。経過ターンはフロア共通。距離は骸と実行先／選択敵の距離。視界内は骸の視界で評価。隣接敵数は骸なら周囲の魔物数、敵なら隣接する骸の有無（0／1）。一撃で倒せるは通常攻撃で相手を倒せるかを判定し、骸では「攻撃する」とのみ組み合わせ可能。既知の回収品は骸の発見記録を参照する。将来の条件整理で重複を減らすかは別途検討する。

## 保存と移行

保存バージョン16を維持し、actorRuleRevision:1で意味の変更を識別する。敵のcontrolに歩行履歴・自己強化・防御残数等を保存して検証する。階を移れば敵ごと再生成され、共通使用回数もリセットする。予測は本編と同じtickを複製状態で使用する。

旧版の敵指定行をそのまま敵操作へ切り替えない。旧敵／HPの低い敵／攻撃力の高い敵は自分へ変換し、HP・半分以下・一撃判定があった旧行は確認のため無効化する。旧敵のHP条件を自分のHP条件として勝手に有効にしない。廃止2ターゲットの所持は各5欠片で補填し、図鑑は敵へ統合。床の旧ターゲット箱・未決定候補は同レアリティのHP条件カードへ置換。移行は繰り返しロードしても補填を重複しない。旧プリセットも同様に解釈し、新規プリセットは改訂番号を保存。プリセットは最大10行に対応する。

新保存を旧コードで読む前方互換は保証しない。将来の仲間指定はターゲット定義・actorCanUse・実行者アダプターを追加する構成にし、IDや仲間の数値は未決定。

## 今回変えないこと／今後の検討

スキルの種類数・レアリティ・基礎倍率や回復率、オーグメントの種類数と星倍率は調整しない。固定HP50%条件と可変HP条件の重複、視界内条件の使い道、敵実行時の隣接数条件、条件をさらに汎用化する設計、敵操作の長期難易度は検討課題。運試しの報酬は説明に合わせ8欠片へ統一し、誤って探索家オーグメントの倍率を参照していた処理を修正した。
