# オーグメント・カード追加案

2026-11-03。「駆け上がる記憶」は後続依頼で採用済み（300ターン未満でClear時に最大HP15%回復）。それ以外は提案であり未実装・未決定。監査に挙げた罠回避・戦術競合は2026-11-04に修正済み。常時成立条件の改善は別課題。

## 優先して追加したい条件カード

|案|組合せ例|役割|仮レアリティ|
|---|---|---|---|
|増援までNターン以下|自分＋増援まで30ターン以下→階段を上る|残り時間で撤退。現在の経過ターン条件は固定値だが、これは現在の固定60ターン周期に追従する|EPIC|
|現在装備より強い|自分＋現在装備より強い→武器／防具を取得|弱い装備に寄り道せず、滞在時間を節約。武器は攻撃力、防具は防御力で比較|NORMAL|
|視界内の敵がN体以上|自分＋視界内に敵3体以上→転移／退避|既存の隣接敵数より早く包囲の兆候に反応|EPIC|
|ボスが生存中|敵＋ボスが生存中→敵を攻撃|通常探索とボス戦で指示を切り替える。対象をボスに限定する設定も検討|NORMAL|

初回追加は「現在装備より強い」と「増援までNターン以下」を推奨。武器・防具カードの細分化に意味を付け、増援との駆け引きを生む。全対象を取得する一括カードは再追加しない。自分までの距離や常に視界内の敵など、必ず成立する組合せは避ける。

## テーマ別オーグメント案（数値も未決定）

|テーマ|案|仮効果|仮レアリティ|
|---|---|---|---|
|焦燥|駆け上がる記憶|増援初出現前にClearすると最大HPの15%回復|NORMAL|
|熟成|籠城の覚悟|最初の増援が現れてから防御力+4、ただし増援の攻撃力も10%上昇|EPIC|
|満月|無傷の歩み|HP80%以上で8ターン被弾せずに移動すると、次の罠ダメージを1回無効化。消費後に再蓄積|EPIC|
|背水|死線の導き|HP25%以下の間、敵の攻撃を20%で回避。罠には無効|EPIC|
|傷跡|継ぎ接ぎの護り|この階で初めて罠を踏むと、以後その階の防御力+3|NORMAL|
|闘争|退路を斬る|通常敵を倒すと、隣接する他の通常敵を1ターン足止め。ボス・増援には無効|LEGENDARY|

初回追加は「駆け上がる記憶」「死線の導き」「退路を斬る」を推奨。速いClear・低HP維持・包囲突破という異なる方針を作れる。熟成の強化を増援報酬へ結び付けず、増援を倒して欠片や経験値を稼げない現行仕様を維持する。
