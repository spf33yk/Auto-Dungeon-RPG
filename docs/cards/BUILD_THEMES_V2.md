## セット成立条件と表示

同テーマの所持・解放済みスキルを有効な指示に配置した異なる種類数で、同テーマの所持オーグメントを強化する。1／3／6種で★1／2／3、性能1.25／1.5／2倍（仮採用）。0種は☆☆☆。同一スキルの重複は加算しない。条件成立や実使用の回数ではない。星は配置から再計算し、取り外しや無効化で下がる。選択時は取得後の星を予告する。スキル直接強化は廃止。

全スキルは取得・配置・条件成立が必要。発動1ターン。ターゲットは実行者で、自分と敵の使用回数を各階1回で共有。敵は対応25種を使用可能。HP消費は1を残す。回復・消費・ダメージは切上げ、吸命は実ダメージから切捨て。オーグメント由来の悟り補正は維持。整数補正と追加回数は星倍率を掛け切上げ、率は100%まで、発動条件とデメリットは維持する。

専用ホバーウィンドウで説明し、オーグメント名横の星と現在性能を表示。新規行を追加は最大Lv8、指示は最大10行＋常設最終行。複数条件の解放は従来どおり最大6枚。

実行者の対応範囲は[実行者指定v1](ACTOR_RULES_V1.md)、カードの現行表記は[CARD_CONTENTS.md](CARD_CONTENTS.md)を参照。
