# オーグメントとカード取得仕様 v2

更新日：2026-11-03。保存v16。以下は仮採用バランス。

## 入手・進行

初期カードは自分・近くの敵・階段を上る・敵を攻撃・宝箱を取得の5種類。視界条件はLEGENDARYの宝箱報酬へ変更。手紙の箱を開けるカードは宝箱抽選から除外し、初回通常エンド時に確定取得。以後の旅の開始時にも所持する。既存セーブの所持済み視界・手紙カードは取り上げない。手紙本体の条件は通常エンド済みのB15のまま。

通常のカード箱は4候補×35%独立抽選。レアリティをNORMAL70%／EPIC25%／LEGENDARY5%で抽選し、そのレアリティの初期・手紙以外から均等抽選、未所持優先。視界カードの実確率は5%÷抽選対象LEGENDARYカード数（未所持優先を適用）。同じ所持カードは複数行に配置可能。重複取得は欠片5。所持は旅でリセット、図鑑記録は保持。

一括の装備取得（collect-items）と回復品取得（heal-item）は削除。武器／防具／記憶の欠片／薬草／回復の泉の専用カードを追加。泉と薬草も個別に指定する。宝箱・手紙は専用カードで指示する。踏んだ品物の自動取得は維持する。

トラップを避けるは既知の未作動罠を通らない経路を先に探索。同じ目的地への安全経路がなければ罠を通る経路へ切り替える。罠無効化は廃止し、強行通過時も最大HP8%切上げのダメージを受け、罠は作動済みになる。

開始字幕の後、探索開始前にオーグメント3択。B20・B10・B1のボス撃破時にも3択。選択待ちはターン停止し、Escapeで閉じられない。候補・選択待ちを保存するため再読み込みで引き直せない。各回1個、同じ種類は重複選択しない。通常の1旅は計4個。候補は未所持から各候補単位の重みNORMAL70／EPIC25／LEGENDARY5で復元なし抽選する（各レアリティの総確率は残る種類数によって変わる）。テーマを揃える固定セットボーナスは未実装で、効果の組合せそのもので相乗効果を作る。

再生の祈り・窮地の転移は能動スキルカードとして取得と配置が必要。会心・吸命・追撃はオーグメントへ移動し、指示枠を使わない。取得したオーグメントは即時有効で、旅の終了・NewGame・あきらめるでリセット。図鑑は全19種の名前・テーマ・レアリティ・効果と取得状況を初期から表示する。

## 準備画面・予測

上から現在準備中の階のヒント（異変・主な敵）、所持オーグメント（テーマ・名前・効果）、準備メニュー、カード編集。カード一覧と指示行の2列は維持し、長いカード列は横スクロール。オーグメントは独立の図鑑ボタンから参照。配置済みカードの条件編集・並べ替え・ドラッグ／タップ・スキンは維持する。

デバッグの「オーグメント」から19種を選んで取得し、効果を確認できる（使用記録を付与）。

探索の予測は所持オーグメントを本編と同じ計算で適用。ボス撃破後の未選択の追加オーグメントは予測に含めず、そのまま階段到達まで続行する。予測は実データ・選択・乱数を変更しない。今回のバランス変更後の全旅クリア率・所要時間は未計測。旧検証の率・時間は旧コミット専用。

## 保存移行

v2〜15は従来の移行を経てv16へ移行。所持中の会心・吸命・追撃をaugmentsへ変換、旧補助指示行を削除。旧スキル取得記録をprofile.augmentsへ転記。廃止した旧カードIDをownedCards/profile.cardsから除く。未開封の旧補助カード箱は同じ効果の旧rewardId箱へ変換し、内容を保持。既存rewardId箱・装備箱は保持。初回クリア済みは手紙カードを補完。旧一括取得の行は武器／薬草へ置換し、対応する個別2種を補填する。探索途中の旧セーブへ開始3択を遡って付与しない。現在の階・装備・HP・進行は維持する。
