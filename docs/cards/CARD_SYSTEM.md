# カード・オーグメント

現行カード52種＝ターゲット2・条件8・アクション12・スキル30。オーグメントは30種。全定義は[CARD_CONTENTS](CARD_CONTENTS.md)と[BUILD_THEMES_V2](BUILD_THEMES_V2.md)から参照する。数値は仮採用。

## 所持と配置

初期6種は自分・敵・階段を上る・1ターン待機・宝箱を取得・指定ターン経過。ターゲット2種と初期カードはドロップしない。手紙の箱を開けるは初回通常END後に付与し、以後の旅でも補完。所持は旅ごとにリセット、図鑑は引継ぐ。

ターゲット＋条件（全AND）＋アクション／スキル。初期2行・最大10行、1行4〜6枚（条件2〜4枚）。最終階段行は別枠。スキルは取得・解放・有効配置・実行条件が必要。骸と敵で各階1回を共有し、オーグメントは所持で自動適用。敵の詳細は[実行者指定](ACTOR_RULES_V1.md)。

## 取得・図鑑

カード箱のレアリティ抽選はNORMAL70%／EPIC25%／LEGENDARY5%。未所持優先。開封時に種類別候補を保存し、種類を一度選んでから縦の候補一覧で選ぶ。重複は記憶の欠片5個。スキル箱は赤、LEGENDARY箱は金エフェクト。手紙と初期カードは候補から除外。候補不足の種類だけ下位レアリティを使用する。

図鑑は未所持を含む全カードを掲載し、レアリティ・今回所持・発見記録を表示。新規取得はNEW、準備出発成功時に解除。オーグメントの図鑑は全30種と効果・テーマ・記録を表示する。

回復の取得指示は「回復ポーションを取得」の1種類。泉カードは新規抽選・図鑑から除外し、旧所持・配置・未開封箱・選択待ち候補・プリセットは回復ポーションカードへまとめる。回復量は10HP、泉だった床も回復ポーションにする。

## 保存互換

保存v16とactorRuleRevision:1を使用。旧ターゲット指定は敵操作へ勝手に切り替えず、自分へ移行し旧条件行を確認のため無効化する。廃止ターゲット・戦術・回収品なし条件の所持は記憶の欠片5個を一度だけ補填。旧攻撃行は削除、固定HP50%条件は可変HP条件へ置換、回収品なし条件は除去して行を無効化。未開封箱・候補は同種／レアリティを保つ固定置換とし乱数を消費しない。ターン条件は既存保存にも補完し宝箱から除外する。

旧プリセットも同じ改訂で移行。旧常時スキルはオーグメントへ移行する。移行は再読込で補填を重複しない。新保存を旧コードで読む前方互換は保証しない。

指示数・カード内編集・プリセット・星・停滞対策は[SPEC](../../SPEC.md)第11節に従う。
