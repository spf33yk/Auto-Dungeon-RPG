# カード・オーグメント仕様

現行はカード57種（ターゲット4・条件9・アクション14・スキル30）、オーグメント30種。詳細な値は[現行60種一覧](BUILD_THEMES_V2.md)、進行・保存・UIは[SPEC第13・14節](../../SPEC.md)を参照。旧19オーグメント・6スキルの構成はGit履歴に保持する。

## 指示と取得

初期5枚は自分・近くの敵・階段を上る・敵を攻撃・宝箱を取得。編集行2→8、1行の枚数4→6を別々に拡張する。所持は旅ごとにリセット、発見記録は周回引継ぎ。手紙のカードは通常エンド初回達成で確定取得。選択宝箱は同種類・同階級から未所持を優先して候補を作り、通常3枚／宝探しの勘あり4枚まで。選択は1枚、運命の賽の当たり時は2枚。キーは不要。

ターゲット1＋AND条件0以上＋アクション／スキル1で構成。自分をターゲットにした攻撃スキルは、自分の条件を判定して隣接敵へ発動する。スキルは各階1回・1ターン使用。未所持のカードは配置不可。使用済み・不成立・無効行はスキップし、他の行や基本AIを実行する。最終行の自分→階段を上るは変更不可で容量を消費しない。

行を有効／無効にして試せる。プリセット10件は端末別に保持し、未所持や枠不足時は読み込まず元の指示を維持する。探索中・ひとやすみ中は編集不可。

## テーマとセット

探索家・修行僧・狂戦士・守護者・勝負師の5テーマ。各テーマのオーグメントとスキルはNORMAL3・EPIC2・LEGENDARY1。同テーマの記憶を所持して有効な行にスキルを配置すると、そのスキルのセット効果が有効。同テーマ所持数による重ね掛けはしない。

オーグメント選択では選んだ場合のセット成立、準備では成立テーマの帯、カードではテーマアイコン・SET文字・発光・説明を表示。図鑑も同じ判定を使う。通常のターゲット／条件／アクションは共通で職業を付けない。

## 分類と重み

オーグメント候補は個々の未所持種の重みNORMAL70・EPIC25・LEGENDARY5で重複なく抽選。各テーマの種類数・レアリティ構成が同じなので全未所持の最初の1枠ではテーマごと20%。取得済みを除く後続の抽選比率は変化する。カード宝箱の最初の階級抽選70%／25%／5%とは区別する。

旧ID置換、途中階使用回数、強化効果の保存、増援を撃破依存効果へ含めないルールはSPEC第14節に従う。全バランスは仮採用。
