# カード・オーグメント仕様（現行）

2026-11-07。カード53種（ターゲット2・条件8・アクション13・スキル30）、オーグメント30種。全カードの名前・性能・対応は[現行一覧](CARD_CONTENTS.md)、実行者と移行は[実行者指定v1](ACTOR_RULES_V1.md)、数値は[60種一覧](BUILD_THEMES_V2.md)を参照。

## 指示と取得

初期6枚は自分・敵・階段を上る・攻撃する・宝箱を取得・指定ターン経過。指示は2→10行、カードは1行4→6枚へ別々に拡張。ターゲットは2種類を保証所持し、宝箱には出ない。カード所持は旅ごと、発見記録は引継ぎ。手紙のカードは初回通常エンド後に取得する。

ターゲットは実行者を指定し、AND条件0枚以上とアクション／スキル1枚を組む。HP条件は実行者自身のHPを参照。自分の攻撃は敵へ、操作する敵の攻撃は骸へ向かう。最も近い視界内の通常敵1体を操作し、ボスは除外する。敵への指示で骸の行動枠を使い、通常AIを同じターンに二重実行しない。

全30スキルは有効な指示と条件成立で発動し、骸・敵で各階1回を共有。発動後の持続効果は技能説明どおり残る。敵は対応25種のみ使える。使用済み・不成立・無効行はスキップし、他の行や基本AIへ進む。最終行の自分→階段を上るは変更不可で指示容量を消費しない。

宝箱はアクション・条件・スキルから種類を一度だけ選び、固定した候補から1枚を取得。種類に該当レアリティがなければ下位候補を明記。候補上限3、宝探しの勘で4〜5。運命の賽の当たり時は同じ種類で最大2枚。全候補を開封時に保存し再抽選しない。取得完了後は探索を再開する。旧ターゲット箱は対応レアリティのHP条件へ移行。

## 自動効果とテーマ

オーグメントは所持で自動適用し、配置不要。スキルに常時発動型は置かない。旧会心・吸命・追撃のスキルIDは保存互換だけに保持し、新しいスキル一覧・報酬選択から除外する。戦術・罠回避のアクションは条件成立中の行動方針であり、スキルとは区別する。

5テーマは探索家・修行僧・狂戦士・守護者・勝負師。各テーマはオーグメント／スキルそれぞれNORMAL3・EPIC2・LEGENDARY1。同テーマの有効配置スキル種類数1／3／6でオーグメント★1／2／3、性能1.25／1.5／2倍（仮採用）。自分と敵への配置を区別せず数えるが、敵自身は骸のオーグメント効果を持たない。重複スキルは加算しない。0種でも☆☆☆を表示する。

## 保存・互換と残課題

保存v16＋actorRuleRevision:1。旧敵対象の指示は自分へ置換し、HP等を参照する旧行は確認のため無効化。廃止2ターゲット所持は各記憶の欠片5を補填し、繰り返し読込で重複しない。旧プリセットにも同じ移行を適用し、最大10件・各10行に対応。仲間の指定、条件の重複整理、敵操作を含む最終バランスは未決定。新保存を旧コードで読む互換は保証しない。
