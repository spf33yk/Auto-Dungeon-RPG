# カード取得・レアリティ設計 v1

更新日：2026-11-03。現行実装は保存v14。

## 確定した方針

カード所持は種類単位。同じ所持カードは複数の指示行へ使え、配置・取り外しで消費しない。初期は自分・近くの敵・視界内にある・階段を上る・敵を攻撃・宝箱を取得の6種類。追加は宝箱から入手し、準備画面でだけ配置できる。未所持カードを配置・実行・保存できない。死亡後の新しい旅・NewGame・あきらめるでは所持と能力をリセット。図鑑の取得記録は周回後も維持する。

カード図鑑は旧スキル図鑑を統合し、全29種類を初期から名称・効果・レアリティ付きで公開する。所持中／過去に取得・現在未所持／未取得を区別し、カテゴリで絞り込める。スキル一覧には再生・転移・会心・吸命・追撃の5種類を表示し、全種類で取得と指示行への配置が必要。会心・吸命・追撃は条件成立中の攻撃に効果を加える補助スキルで、それ自体はターンを消費せず移動や攻撃を止めない。取得しただけでは発動しない。

## 仮採用バランス

NORMALは基本行動や単純な条件、EPICは対象の比較・距離やHPによる精度向上・緊急行動、LEGENDARYは一撃判定・戦術・罠無効化・転移・吸収・追加攻撃など攻略を大きく変えるカードへ割り当てる。強さだけでなく情報判断と生存能力を評価し、将来調整可能。

通常フロアの宝箱は従来どおり4候補×35%の独立抽選。内容は階生成時に固定し、NORMAL70%／EPIC25%／LEGENDARY5%を先に抽選し、同レアリティの初期カード以外から均等抽選。同レアリティに未所持があれば優先。階生成時点の所持を参照するため同じ階に同カードの箱が複数出る場合がある。重複取得は記憶の欠片5へ変換。初期6種類は通常の追加抽選に入れない。敵ドロップの有無の二段階方式は維持し、成功時は装備100%へ変更。新規生成では敵が再生カードを直接落とさない。

スキルカード（能動・条件付き補助）が入る箱は赤色。LEGENDARYカードの箱には色に関係なく金色の光と粒子を追加。未発見の箱は表示せず、既知だが視界外の箱は暗くする。動きを減らす設定時は光を固定する。手紙の箱はカード箱に変換せず、物語の条件・配置を維持。

## 保存と旧データ

ownedCardsは「カテゴリ:ID」の配列、profile.cardsは過去に取得した種類の記録。旧v2〜v13からv14へ移行し、初期6種類＋設定済み指示の対象・条件・実行カード＋現在のスキルを所持として復元。旧スキル図鑑の発見も統合し、未使用の全カードを一括解放しない。現在の階・装備・HP・記憶の欠片・手紙・旧宝箱の内容・図鑑記録は維持する。既存のrewardId宝箱・旧装備箱は従来どおり取得でき、新しい階からcardId宝箱になる。
