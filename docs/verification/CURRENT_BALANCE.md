本番newGame／beginExploration／tick／ascend／equipBest／upgrade／chooseAugment／selectChestCategory／chooseChestCardで検証。初期HP54・Lv1・記憶の欠片12・初期6カード・初期装備。B30の準備を省略し、開始3択も実候補から選択。未所持の付与、HP変更、敵削除、乱数巻戻し、デバッグ強化なし。購入UIのない生命・剣技・守護の強化は0。各階で指示とvalidateSaveを検査する。

共通で所持済みの回復・防御・攻撃スキルを優先し、指示行数・視界購入、最強装備への変更を行う。直行は回収行なし、回収は回復ポーション・宝箱・防具・武器・記憶の欠片を候補へ追加、テーマは同テーマの報酬・配置を優先、敵待機は隣接条件の取得後に敵への待機指示を優先する。敵操作一般の比較ではない。点数と手順はスクリプトを参照。

シードは(1001＋104729×i) mod 10000000、i=0〜99。同じシードでも選択により後の乱数消費が変わる。各階2000ターンで打切り。成功したprofileだけをseed＋19で2周目に引き継ぐ条件付き標本。
