# 現行バランスの通し検証

2026-11-08。ゲーム処理の基準コミット329137b。本報告と同時変更のscripts/verify-clearability.jsを使用。ゲーム本体・難易度・保存形式は変更していない。

## 結論

通常エンドまで到達できることは確認できたが、今回の固定準備方針では初回400試行中2回のみ。現行を適切な難易度と判断する根拠は不足しており、特に序盤の生存と装備・回復カードが揃うまでの導線を優先調整すべき。

400試行は100個の同じシードを4方針で比較したもの。400個の独立シードでも、人間の一般的な勝率でもない。方針は最適化済み攻略ではなく、合法操作の固定ヒューリスティック。0回の方針がクリア不能だという証明にはならない。

TRUE ENDは分岐未実装なので、到達率・所要時間を算出できない。

## 条件と再現方法

実行：node scripts/verify-clearability.js 100 test-results/current-balance.json

- 本番のnewGame／beginExploration／tick／ascend／equipBest／upgrade／chooseAugment／selectChestCategory／chooseChestCardを使用。
- 初期HP54・Lv1・記憶の欠片12・初期6カード・初期装備で開始。B30は初期指示のまま、開始3択から必ず実際の候補1個を選ぶ。
- 操作は準備中の最強装備・所持カード内の指示編集・指示行の購入・視界の購入、報酬候補の選択だけ。現在購入UIのない生命／剣技／守護を購入しない。全試行で該当3段階が0、debugUsed=falseを確認。
- 未所持カードの付与、HP直接変更、敵削除、乱数の巻戻し、デバッグ強化、探索中の指示変更は行わない。各階でvalidateSaveと配置条件を検査。
- シードは(1001＋104729×i) mod 10000000、i=0〜99。全方針で同じ系列。合法な選択に応じて消費する乱数が変わるため、後続の戦闘・候補まで同一とは限らない。
- 回復・防御・攻撃の取得済みスキルを優先。HP条件を所持していれば回復65%以下・転移25%以下等を付ける。未所持条件は使わない。敵攻撃スキルは使用しない。
- 回収・テーマ・敵待機方針は宝箱→防具→武器→記憶の欠片の取得指示を候補へ加える。取得済みのハート／泉もHP条件付きで使用する。各方針は容量内で上から採用し、最終階段行は本編の常設行に任せる。
- 直行方針は回収指示を設けず、宝箱行は1000ターン条件のため通常は発動しない。テーマ方針は所持オーグメントと同テーマのカードを選びやすくし、残り枠へ同テーマスキルを追加する。
- 敵待機方針はテーマ方針を基に、隣接条件を取得後、敵＋相手と隣接＋1ターン待機を最優先。敵操作一般を代表するものではない。
- オーグメント候補の選択は吸命・防御・致命傷耐久などを優先する固定点数。テーマ方針では所持スキルとの一致も加点。スクリプト内の点数を含め再現可能。
- 各階2000ターンで打切り。今回の初回最大は690ターンで、打切りは0回。初回成功2件だけ対応profileを引き継ぎ、seed＋19の2周目を検証した。これは成功種から派生する条件付き標本。

詳細JSONはローカルtest-results/current-balance.json。軽量な[試行CSV](current-balance.csv)と[集計JSON](current-balance-summary.json)をリポジトリで保持。計算時間は約118秒であり、ゲーム内の所要時間ではない。

## 停滞と回帰確認

初回400件で進展なしによる基本行動復帰は計311回。2000ターン打切りは0件。最大690ターンで、1000ターン超の本番介入はこの通し試行では未到達。待機8／解除20／進展なし10／復帰20／階1000は専用自動テストでも確認する。

過去に往復が記録された3シード1781394／1990852／6913115を4方針で追加確認（12試行）。全てB29〜B26で死亡したため、過去に停滞したB7／B24／B25の該当場面まで到達していない。今回打切りがなかっただけで過去の往復が完全解消したとは報告しない。全マップ・全カード構成の生存／進行も保証しない。

## 改善の優先候補（未適用）

1. 序盤の回復・装備・能動スキルに触れる機会。B29で初期防具・カードなしの死亡が多く、ビルドを組む前に終わりやすい。
2. 能力強化の購入UI廃止後の基礎値、敵火力、休息15%の釣り合い。購入できない強化を使った旧成績は判断材料にしない。
3. 回収を続ける費用と、手に入る装備・回復の見返り。中盤到達は伸びても完走につながりにくい。
4. 敵操作の消費行動と見返り。待機を指示するだけでは骸も行動できず、今回の構成では早期死亡が増えた。
5. 成功しやすい構成・初心者構成・各テーマ専用構成の追加比較と人間の実プレイ。今回の固定方針を最適解として扱わない。

数値・取得条件の変更はこの検証には含めていない。次の調整後は同シードで再測定する。UI変更のないロジック検証のため公開版走行は省略。ブラウザ描画速度・準備時間・スマホ実機は未測定。
