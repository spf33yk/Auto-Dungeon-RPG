# 骸の旅路 — 記憶の迷宮

スマートフォン・PCのブラウザで遊ぶ、自動探索ダンジョンRPGの通常エンド版です。B50から50階を上り、地上1Fを目指します。

## 起動

Node.js 20以降で、リポジトリ内から実行します。外部パッケージのインストールは不要です。

```sh
node server.js
```

PCでは http://localhost:4317 を開きます。同じWi-Fiのスマートフォンからは `http://PCのLANアドレス:4317` にアクセスできます。必要に応じてOSのファイアウォールでローカルネットワークからの接続を許可してください。

## 遊び方

- B50ではスキルを振り分けず探索を開始します。初期12ptはB49到達後の準備から使えます。移動・戦闘・拾得は自動です。
- 速度は1倍・2倍・4倍。探索中は一時停止・指示変更ができます。
- 階段を上ると休息で最大HPの22%を回復し、次の準備画面へ移ります。
- 装備タブで武器・防具を交換します。未鑑定品は能力不明、呪い品は装備すると外せません。
- 鑑定の記憶を取得すると1個3ptで鑑定、解呪の記憶を取得すると1個5ptで解呪できます。
- 合成の記憶を取得すると、同名・鑑定済み・非呪いの装備を2個使い、未強化同士は+1、強化済み同士は合成値を合計できます。片方だけ未強化の場合は合成不可です。素材1個消費、追加ポイント不要、上限+20。
- 19種類の条件付き指示を優先順位順に設定できます。基本2種類以外は各指示を個別のスキルで解放します。初期2枠で、指揮の記憶により最大8枠。収集・全探索・生存判断・退避判断・視界拡張・再生・戦術判断もスキルで取得します。戦術未取得では敵の強さを見て攻撃対象を選別しません。
- 画面上部の図鑑アイコンで攻撃力・防御力を確認できます。モンスターは視認時、装備は入手時に登録。未鑑定の種類の名前・能力は鑑定後に公開します。
- 図鑑を開いている間は停止し、閉じると元の停止状態へ戻ります。
- B1踏破後「地上1Fへ」で通常エンド。次の旅では能力・かけら・装備をリセットし、図鑑と通常エンド記録を引き継ぎます。
- 通常エンド後に絆の記憶が解放され、取得するとB25で手紙を入手可能です。TRUE本編・100F共闘は後続制作のため、現版は手紙があっても通常エンドに進みます。

序盤は剣技・守護を上げ、装備を集めて交換することが助けになります。鑑定・解呪用のポイントも確保してください。

## GitHubから遊ぶ

[ブラウザ版を開く](https://spf33yk.github.io/Auto-Dungeon-RPG/)

GitHub Pagesで公開します。`main` ブランチのルートを公開元とし、更新をpushすると自動で反映されます。PC・スマホとも上記URLから遊べます。保存はブラウザごとの端末内保存です。localhost版の保存は共有されないため、移したい場合はデバッグの書き出し／読み込みを使ってください。

## 保存

端末のブラウザに自動保存します。再読み込み後の探索は一時停止状態で復帰。別タブへ移ったときも停止します。保存できない場合は記録欄に表示します。

通常版は `abyss-normal-v2` に保存し、旧5階試作の `abyss-prototype-v1` は変更せず残しています。旧版の旅からの自動移行は行いません。図鑑・達成記録も端末内の保存で、他端末との同期はありません。

## 構成・検証

- `data.js`：10区間・20種の敵・20種の装備・27スキルの共通データ。
- `game-engine.js`：探索・戦闘・装備・周回・図鑑・保存検証。`engine.js` は公開用の入口。
- `app.js`：画面操作、仮ドット絵のCanvas描画、効果音、自動保存。
- `style.css` / `screens.css`：既存画面のレスポンシブ表示。見栄えの磨き込みは後続作業。

```sh
node --test
```

38件のテストで、全50階・複数シードの地形連結、戦術スキル、装備・呪い・鑑定・合成、図鑑、周回、保存、通常エンドまでの進行に加え、B25メッセージ、入手順、樹の分類、旧保存の移行、デバッグ操作を検証します。素材は既存のオリジナル仮ドット絵を使用し、効果音はWeb Audioで生成します。

準備画面はメインに4系統の記憶の樹、右に探索と共通のステータスを表示します。装備・図鑑は武器／防具タブごとに入手順（初期選択）・攻撃順・防御順で並べ替え可能です。通常宝箱は4候補・各35%の配置抽選です。

「⚙ デバッグ」では指定階への移動・1階スキップ・HP回復・かけら追加・スキル最大化・装備生成・JSONセーブの書き出し／読み込み・初期化ができます。実際の保存へ反映されるため、確認用の進行を残す場合は先に書き出してください。初期化は確認後に実行し、旅だけの初期化では図鑑・達成記録を残します。

保存形式はv5へ自動移行し、旧通常版v2〜v4の進行・図鑑・解放済み指示を維持します。旧個体の正確な入手日時は未記録のため順序を補完し、移行後の入手順を記録します。`skill-tree.js` は樹の分類、`debug-tools.js` はデバッグ処理を管理します。

記憶の樹は4系統タブのノード表示です。探索指示の17ノードを初期表示し、マウスオーバー／キーボードフォーカスで効果・前提・費用を確認できます。スマホはタップして下の詳細から習得します。

難易度を強化し、敵6〜10体・敵能力上昇・最低被ダメージ20%・泉2個（14HP回復）・階段後の休息22%に変更しました。新しい敵と泉の配置は次の階から適用します。
