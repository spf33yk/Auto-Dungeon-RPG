# 骸の旅路 — The Remains' Journey

スマホ・PCブラウザ向けの自動探索ダンジョンRPG。B30から地上1Fへ向かう通常エンド版です。更新日：2026-11-08。保存形式v16。

[ブラウザ版を開く](https://spf33yk.github.io/Auto-Dungeon-RPG/)

全30スキルに専用8コマの発動エフェクトを表示します。回復・防御は使用者、攻撃は命中対象の中心へ前面表示し、探索を止めません。

## 起動

Node.js 20以降で次を実行します。外部パッケージのインストールは不要です。

```sh
node server.js
```

PCでは http://localhost:4317/ 。同じWi-FiのスマホはPCのLANアドレスとポート4317へ接続します。端末内の保存は公開版・localhost・端末・ブラウザごとに別です。

## 遊び方

- NewGame／LoadGame／Optionから開始。骸版の開始前映像はスキップでき、オプションで自動スキップも設定できます。LoadGameは確認後に保存された旅を再開します。
- 指示の土台は有効／無効の隣のボタンで折りたたみ可能。閉じると優先度と指示文を1行表示し、行全体をドラッグできます。開閉状態も保存します。
- 「固定指示」は隣接攻撃と階段探索の2行を初期折りたたみで表示。離れた敵を自動では追いかけません。4種類のカードと一覧タブを色分けし、予測には準備開始時との差も表示します。
- 「思い出す」から字幕・開始オーグメント3択へ進みます。B30への準備画面はありません。
- 回復は回復ポーションに統合。旧セーブの泉と泉カードも回復ポーションへ読み替えます。回復ポーションは瓶で表示し、階段は横向きの上り方向を保って立体的に描き直しています。
- 罠は棘・転移・拘束・衰弱・警報・霧の6種類。骸と敵が踏むと作動し、50%で壊れます。残った罠は踏み直すと再作動します。
- ハウス入場は下部のメッセージ枠で確認し、クリック／タップ・Enter／Space／Escapeで再開。スキル発動は探索を止めずに約2秒表示します。
- 敵は攻撃時にため・踏み込み・復帰と攻撃マークを表示します。通常敵・ボス・操作中の敵に共通で、攻撃判定やダメージは変わりません。
- 移動・戦闘・拾得は自動。速度は0.5／1／2／4倍。「ひとやすみ」で停止・再開できます。探索中は指示を編集できません。階段カードを外しても、指示が実行できないときは基本行動で探索・階段への移動を行います。
- Clear後の準備では、探索指示と装備/ステータスを切り替えます。カードはドラッグ、またはカードと配置先を順にタップして配置します。行の番号をドラッグ、または番号と移動先の行をタップして並べ替えます。上下ボタンはありません。
- 初期は自分・敵・階段を上る・宝箱を取得・指定ターン経過と応急手当の6枚を所持し、宝箱では選んだ種類の全レアリティから抽選した最大3候補から1枚を選択。初期2行・1行4枚から最大10行・1行6枚へ別々に拡張できます。能動スキルは取得とカード配置、オーグメントは取得だけで有効です。同テーマの有効配置スキル1／3／6種類で★1／2／3となり、[個別成長表](docs/cards/AUGMENT_GROWTH.md)に従ってオーグメントが強化されます。
- 装備は武器／防具に分け、入手順・攻撃力順・防御力順で並べ替え、「最強装備」でまとめて更新できます。鑑定・解呪・合成・鍵は現在の本編で使用しません。
- 探索指示画面で記憶の欠片を使い、指示行数・カード枚数・視界の3項目を購入。レベルアップでは最大HP・現在HPが3増加します。視界は初期半径3の四角形判定（明暗の見た目のみ円形）で、壁によって遮られます。
- B20・B10・B1は固定ボス部屋。開始時とB20・B10のボス撃破時にオーグメントを3択から1つ選びます。長居すると300ターン目から60ターンごとに増援が出現します。
- 図鑑はモンスター・装備・カード（スキルを含む）・オーグメントの4種類。図鑑・設定・チュートリアル表示中は探索を停止します。
- ログは3行分を確保し、更新から5秒で隠れます。マウスオーバー／タップで再表示し、スクロールで履歴を読み、記録アイコンで全件表示できます。
- 初回はB1クリア後に地上で通常エンドを迎えます。次の旅からB30の開始地点の隣にある遺書の宝箱を開けられ、固定探索指示で回収します。
- 遺書を取得すると、紙面が画面中央に現れて本文を読めます。初回通常エンド達成後はチュートリアルを表示しません。デバッグの「遺書・ボス回想」で、遺書と周回別の各回想を確認できます。
- B20・B10・B1のボス撃破後に周回に応じた字幕が流れます。遺書を持って地上へ着くとTRUE ENDとなり、タイトルが倅の旅路に変わります。


## 画面とスマホ

16:9を保ち、横向きスマホでもPCと同じ構成です。横長画面では左右に余白が残ります。準備枠はHUDの下から始まり、左右・下辺はゲーム領域の端に一致します。端末全体の端へ引き伸ばしません。

横向き667×375・844×390・932×430相当で表示を確認し、小型画面で1フロアの戦闘・Clear・次階準備まで確認しています。これはPCブラウザ内のサイズ再現で、スマホ実機・タッチドラッグ・Safariの回転／全画面は未確認です。全画面・横向き固定はブラウザが許可する場合に利用します。

チュートリアルはB30探索、B29〜B26準備に分けて自動表示します。案内の本文に沿って次へ進み、最後は「完了」を押します。オプションから現在階の案内を再実行できます。ミニマップは小／中／大、標準は中。準備スキンは古金／黒鉄／骨白／黒曜石。BGMは場面別・ループ再生で音量を設定できます。

## 保存とデバッグ

ゲーム保存はlocalStorageのabyss-normal-v2（v16）、端末設定はabyss-ui-settings。探索中の保存はLoadGame後に停止状態で再開します。旧保存v2〜v15は正規化・検証を経て移行します。旧5階試作のabyss-prototype-v1は自動移行しません。

オプション内のデバッグで階移動・HP回復・記憶の欠片・装備・カード・オーグメント・JSON書き出し／読み込み・初期化を確認できます。実際の保存へ反映します。旅だけの初期化と全データ初期化を区別しています。

## 検証と公開

```sh
node --test
node scripts/update-assets.js --check
```

ブラウザ用JS・CSS・対象素材を変更した場合は、先に `node scripts/update-assets.js` を実行します。mainへのpush後、GitHub ActionsのテストとPages公開は別々に確認します。コミット成功だけでは公開完了とは扱いません。公開走行は必要性を判断し、毎回の必須作業にはしません。

タイトルは背景とロゴの準備で表示し、スキル素材の読み込みを待ちません。出発時にダンジョン素材が未完了なら、その時点で読み込みを待ちます。

通常攻撃・攻撃スキルに短い接触停止・白フラッシュ・反動・火花・粒子・斬撃軌跡を表示し、ダメージ数字は跳ねて消えます。倍速では停止を短縮し、4倍速は停止なし。オプションで画面揺れをOFFにでき、OSの「動きを減らす」にも対応します。

モンスターハウス・トラップハウスの専用BGMと確認通知は、部屋へ移動し終えてから開始します。確認待ちやひとやすみ中も足踏みは続きます。ハウスとスキルの通知枠は同じサイズで表示領域内へ配置します。

準備中の「一括折りたたみ」で固定指示を含む全行を閉じられます。忘却の霧のBGMは準備中には流さず、探索を始めた時に切り替えます。

忘却の霧は青灰色の煙と塵が流れる演出です。敵は足元を固定した2pxの屈伸で待機し、攻撃・被弾時には止めます。「動きを減らす」設定では霧と敵待機を静止表示します。

探索指示は「前に戻す／次に進む」で編集を取り消し・やり直しできます。「拡張機能」から記憶の欠片で拡張を購入し、一括展開・一括折りたたみで表示を整理できます。オーグメントは確認後に取得します。

探索の照明は暖色の柔らかな光です。外周の地形を薄暗く残し、視界拡張で広がり、忘却の霧では実際の視界に合わせて狭まります。

オプションの「探索画面の明るさ」で0〜100%に調整できます。50%が標準。「明るさを標準に戻す」で元へ戻せます。設定は端末に保存します。

「拡張機能」でリロール権やポーションを購入し、同種の未配置カード2枚＋記憶の欠片10個でカードを再抽選できます（仮バランス）。回復ポーションは10個の記憶の欠片でストックを購入し、探索の「ひとやすみ」で1個を消費してHP10回復。満タン拾得もストックされます。所持権・ストックはこの旅の間有効です。カード購入は含みません。

新しい旅は応急手当・旅人の外套（未装備）・回復ポーション1個を所持。案内はB30〜B26へ分けて表示します。リロール権はツリーで繰り返し購入し、カード／オーグメント選択画面で消費できます。

リロールはオーグメント候補の下、カードは種類選択後の画面に表示します。

拡張機能の取得前提はありません。装備を鍛える機能は現在利用できません。

「拡張機能」は装備/ステータスの右隣にあります。解放費用は不要。カード再抽選は同じ種類の2枚を使い、回数制限なく利用できます。

無効にした探索指示は行数枠を消費しません。装備/ステータス画面は、主要能力・装備中の品・比較付き所持品に整理しました。細かい能力は「詳細ステータス」から確認できます。

ほころびた外套の基礎防御力は1です。
