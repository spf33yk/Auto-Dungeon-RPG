# 骸の旅路 — 記憶の迷宮

スマートフォン・PCのブラウザで遊ぶ、自動探索ダンジョンRPGの通常エンド版です。B30から30階を上り、地上1Fを目指します。

## 起動

Node.js 20以降で、リポジトリ内から実行します。外部パッケージのインストールは不要です。

```sh
node server.js
```

PCでは http://localhost:4317 を開きます。同じWi-Fiのスマートフォンからは `http://PCのLANアドレス:4317` にアクセスできます。必要に応じてOSのファイアウォールでローカルネットワークからの接続を許可してください。

## 遊び方

- 最初は「思い出す」ボタンだけで探索を開始します。B30への支度画面はありません。初期12ptはB29到達後の準備から使えます。移動・戦闘・拾得は自動です。
- 速度は1倍・2倍・4倍。探索中は一時停止・指示変更ができます。マップ下部の帯に、現在の判断を自然な独り言の字幕で表示します。詳細な判断はステータス・ログで確認できます。
- 階段を上ると休息で最大HPの22%を回復し、次の準備画面へ移ります。
- 装備タブで武器・防具を交換します。本編の装備はすべて鑑定済み・呪いなし。拾得時の+値は維持します。
- 鑑定・解呪・合成はTRUE END後のエンドコンテンツとして後続制作します。現在の本編では利用できません。
- 19種類の条件付き指示を優先順位順に設定できます。すべて開始時から選択可能です。初期2枠で、指揮の記憶により最大8枠。指揮の記憶で枠を増やし、視界拡張・再生・戦術判断はスキルで取得します。戦術未取得では敵の強さを見て攻撃対象を選別しません。
- 画面上部の図鑑アイコンで攻撃力・防御力を確認できます。モンスターは視認時、装備は入手時に登録。装備は入手時から名前・能力を公開します。
- 図鑑を開いている間は停止し、閉じると元の停止状態へ戻ります。
- B1 Clear後「地上1Fへ」で通常エンド。次の旅では能力・記憶の欠片・装備をリセットし、図鑑と通常エンド記録を引き継ぎます。
- 絆の記憶は削除し、通常エンド達成後はB15で手紙を入手できます（代替条件を仮採用）。TRUE本編・50F共闘は後続制作のため、現版は手紙があっても通常エンドに進みます。

序盤は剣技・守護を上げ、装備を集めて交換することが助けになります。再生の祈りや指示枠の拡張も活用してください。

## GitHubから遊ぶ

[ブラウザ版を開く](https://spf33yk.github.io/Auto-Dungeon-RPG/)

GitHub Pagesで公開します。`main` ブランチのルートを公開元とし、更新をpushすると自動で反映されます。PC・スマホとも上記URLから遊べます。保存はブラウザごとの端末内保存です。localhost版の保存は共有されないため、移したい場合はデバッグの書き出し／読み込みを使ってください。

## 保存

端末のブラウザに自動保存します。再読み込み後の探索は一時停止状態で復帰。別タブへ移ったときも停止します。保存できない場合は記録欄に表示します。

通常版は `abyss-normal-v2` に保存し、旧5階試作の `abyss-prototype-v1` は変更せず残しています。旧版の旅からの自動移行は行いません。図鑑・達成記録も端末内の保存で、他端末との同期はありません。

## 構成・検証

- `data.js`：10区間・22種の敵・20種の装備・7項目の共通データ。
- `game-engine.js`：探索・戦闘・装備・周回・図鑑・保存検証。`engine.js` は公開用の入口。
- `app.js`：画面操作、仮ドット絵のCanvas描画、効果音、自動保存。
- `style.css` / `screens.css`：既存画面のレスポンシブ表示。見栄えの磨き込みは後続作業。

```sh
node --test
```

自動テストで、全30階・複数シードの地形連結、戦術スキル、装備交換・本編での旧機能無効化、図鑑、周回、保存、通常エンドまでの進行に加え、B15メッセージ、入手順、一覧の分類、旧保存の移行、デバッグ操作を検証します。素材は既存のオリジナル仮ドット絵を使用し、効果音はWeb Audioで生成します。

準備画面は探索指示→装備→スキルツリーのメニューを表示し、スキルツリーには3分類・7項目の一覧、右に探索と共通のステータスを表示します。装備・図鑑は武器／防具タブごとに入手順（初期選択）・攻撃順・防御順で並べ替え可能です。通常宝箱は4候補・各35%の配置抽選です。

ヘッダーの「オプション」→「デバッグモード」では指定階への移動・1階スキップ・HP回復・記憶の欠片追加・スキル最大化・装備生成・JSONセーブの書き出し／読み込み・初期化ができます。実際の保存へ反映されるため、確認用の進行を残す場合は先に書き出してください。初期化は確認後に実行し、旅だけの初期化では図鑑・達成記録を残します。

保存形式はv8へ自動移行します。v2〜v5の階数だけ30階へ換算し、v6・v7の階数はそのまま保持。旧4スキルの習得費用を1回返還し、既存装備と未開封宝箱は鑑定済み・呪いなしへ変換します。能力・強化値・入手順・図鑑・指示・手紙・進行は保持します。過去の操作費用と合成素材は返還しません。`skill-tree.js` は一覧の分類、`debug-tools.js` はデバッグ処理を管理します。

スキルツリーは「ステータス」「探索指示枠」「スキル」のカード一覧です。ノードと接続線は表示せず、効果・前提・費用を常時確認し、各カードのボタンから習得します。

難易度を強化し、敵6〜10体・敵能力上昇・最低被ダメージ20%・泉2個（14HP回復）・階段後の休息22%に変更しました。新しい敵と泉の配置は次の階から適用します。

階段到達後の「Clear」メッセージ内で、記憶の欠片の獲得と次階の敵・異変を確認できます。独立した「勇者の残響」欄は削除しました。B30以外ではモンスターハウス12%・トラップハウス12%・霧16%（異変なし60%）を抽選します。B15の手紙は通常エンド達成が必要（仮採用）です。TRUE本編は50階構成で後続制作です。

探索画面は主人公の視界に合わせたズームカメラで追従します。右上にグリッド付きの半透明ミニマップ、マップ下部の帯に思考字幕と「ひとやすみ／探索を再開」、マップ直上に階数・HPバーと現在値／最大値・ATK・DEF・視界範囲・記憶の欠片を表示します。トラップハウスの罠は常時見え、通常階にも25%の確率（異変なしの階のみ）で1〜2個の罠が現れます。B20・B10は固定マップの中ボス階で、撃破すると階段の封印が解けます。

冒頭の副説明文を削除し、余白を詰めています。旧セーブもそのまま利用でき、過去ログと次階ヒントの内容は保持されます。

感覚の記憶は視界半径+1マス×4段階（初期4、最大8）。費用は10→18→26→34ptです。霧では2マス減少します。旧セーブの取得段階は維持し、新効果を適用します。追加請求はなく、次回購入から新コストです。

タイトルの英語名はThe Remains' Journey。サブタイトルを横に置き、章紹介や画面案内の独立見出しを削除しました。オプションを開くと探索は停止し、デバッグを閉じてもオプションが開いている間は停止を続けます。

UIは落ち着いた仮グレーテーマに変更しています。速度ボタンは上部レターボックスの記憶の欠片の右にあります。Clear後の「準備画面へ」は報酬文直下、準備の「探索を始める」はB〇〇への支度の直下にあります。通常のやり直すボタンと凡例・旧Chat欄は削除し、初期化が必要な場合はオプション内のデバッグを利用します。

準備画面では出発ボタンの右に「あきらめる」、その下に準備中の操作説明があります。あきらめるは確認後にB30から新しい旅を開始し、図鑑とエンド達成記録を保持します。装備欄の「最強装備」で、武器は強化値込み攻撃力、防具は防御力が最大の所持品へまとめて交換できます。同値なら現在の装備を維持し、追加費用はありません。

ゲーム画面の上部レターボックスに階層〜記憶の欠片と速度変更、下部に字幕とひとやすみ／探索を再開を配置しています。
