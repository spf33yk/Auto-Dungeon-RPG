# 骸の旅路 — The Remains' Journey

スマホ・PCブラウザ向けの自動探索ダンジョンRPG。B30から地上1Fへ向かう通常エンド版です。更新日：2026-11-04。保存形式v16。

[ブラウザ版を開く](https://spf33yk.github.io/Auto-Dungeon-RPG/)

## 起動

Node.js 20以降で次を実行します。外部パッケージのインストールは不要です。

```sh
node server.js
```

PCでは http://localhost:4317/ 。同じWi-FiのスマホはPCのLANアドレスとポート4317へ接続します。端末内の保存は公開版・localhost・端末・ブラウザごとに別です。

## 遊び方

- NewGame／LoadGame／Optionから開始。骸版の開始前映像はスキップでき、オプションで自動スキップも設定できます。LoadGameは確認後に保存された旅を再開します。
- 指示の最終行に「自分 → 階段を上る」を常設。4種類のカードと一覧タブを色分けし、予測には準備開始時との差も表示します。Clear・死亡時には実際の活躍記録を確認できます。
- 「思い出す」から字幕・開始オーグメント3択へ進みます。B30への準備画面はありません。
- 移動・戦闘・拾得は自動。速度は0.5／1／2／4倍。「ひとやすみ」で停止・再開できます。探索中は指示を編集できません。階段カードを外しても、指示が実行できないときは基本行動で探索・階段への移動を行います。
- Clear後の準備では、探索指示・装備・スキルツリー・ステータスを切り替えます。カードはドラッグ、またはカードと配置先を順にタップして配置します。行の番号をドラッグ、または番号と移動先の行をタップして並べ替えます。上下ボタンはありません。
- 初期は5種類のカードを所持し、宝箱から追加取得。初期2行・1行4枚から最大8行・1行6枚へ別々に拡張できます。能動スキルは取得とカード配置、オーグメントは取得だけで有効です。
- 装備は武器／防具に分け、入手順・攻撃力順・防御力順で並べ替え、「最強装備」でまとめて更新できます。鑑定・解呪・合成・鍵は現在の本編で使用しません。
- 記憶の欠片で6種類の強化項目を購入。レベルアップでは最大HP・現在HPが3増加します。視界は初期半径3の四角形で、壁によって遮られます。
- B20・B10・B1は固定ボス部屋。開始時とボス撃破時にオーグメントを3択から1つ選びます。長居すると300ターン目から60ターンごとに増援が出現します。
- 図鑑はモンスター・装備・カード（スキルを含む）・オーグメントの4種類。図鑑・設定・チュートリアル表示中は探索を停止します。
- ログは3行分を確保し、更新から5秒で隠れます。マウスオーバー／タップで再表示し、スクロールで履歴を読み、記録アイコンで全件表示できます。
- B1 Clear後に地上へ進むと通常エンド。次の旅は能力・所持カード・装備・オーグメント等をリセットし、図鑑と達成記録を引き継ぎます。初回通常エンド後は手紙の箱を開けるカードを取得し、以後B15で手紙を入手できます。

**TRUE END本編・達成後のコンテンツは未実装です。** 手紙を持って地上へ出ても通常エンドへ進みます。デバッグのTRUE END記録切替は倅版タイトルを確認する機能です。

## 画面とスマホ

16:9を保ち、横向きスマホでもPCと同じ構成です。横長画面では左右に余白が残ります。準備枠はHUDの下から始まり、左右・下辺はゲーム領域の端に一致します。端末全体の端へ引き伸ばしません。

横向き667×375・844×390・932×430相当で表示を確認し、小型画面で1フロアの戦闘・Clear・次階準備まで確認しています。これはPCブラウザ内のサイズ再現で、スマホ実機・タッチドラッグ・Safariの回転／全画面は未確認です。全画面・横向き固定はブラウザが許可する場合に利用します。

探索4項目・準備5項目の初回チュートリアルは、オプションからいつでも見直せます。ミニマップは小／中／大、標準は中。準備スキンは古金／黒鉄／骨白／黒曜石。BGMは場面別・ループ再生で音量を設定できます。

## 保存とデバッグ

ゲーム保存はlocalStorageのabyss-normal-v2（v16）、端末設定はabyss-ui-settings。探索中の保存はLoadGame後に停止状態で再開します。旧保存v2〜v15は正規化・検証を経て移行します。旧5階試作のabyss-prototype-v1は自動移行しません。

オプション内のデバッグで階移動・HP回復・欠片・装備・カード・オーグメント・JSON書き出し／読み込み・初期化を確認できます。実際の保存へ反映します。旅だけの初期化と全データ初期化を区別しています。

## 検証と公開

```sh
node --test
node scripts/update-assets.js --check
```

ブラウザ用JS・CSS・対象素材を変更した場合は、先に `node scripts/update-assets.js` を実行します。mainへのpush後、GitHub ActionsのテストとPages公開は別々に確認します。コミット成功だけでは公開完了とは扱いません。公開走行は必要性を判断し、毎回の必須作業にはしません。
