# 骸の旅路 — 記憶の迷宮

起動時はタイトル画面です。NewGameで新しい旅、LoadGameで端末内の続き、Optionで設定を開きます。既存の旅をNewGameで上書きする前には確認します。ゲーム内Optionからタイトルへ戻れます。TRUE END本編はまだ実装せず、Option→デバッグ→「TRUE END達成記録を切り替え」で骸／倅のタイトルを確認できます。

再読み込み時は保存状態とタイトル画像の準備が済むまで「読み込み中…」を表示します。LoadGameで探索中の保存を選ぶと、ひとやすみ状態で再開します。

各図鑑とデバッグ画面は、スクロール中も上部右端の×ボタンから閉じられます。

物語の設定資料は [骸の旅路](story/骸の旅路.txt) と [ストーリー設定](story/ストーリー設定.txt) に保存しています。ストーリー設定を変更するときは関連資料も合わせて更新します。
資料と実装の食い違い・未決定事項は[物語と資料の整合確認](STORY_AUDIT.md)にまとめています。

準備画面は現在のダンジョンを背景にした一画面です。カードリストの対象・条件・行動・スキルを指示の欄へドラッグするか、カードと配置先を順にタップして組み替えます。指示行は見出しのドラッグまたは上下ボタンで並べ替えられます。装備・スキルツリー・状態・旅の記録・図鑑も引き続き利用できます。

探索画面では骸の思考に「▶」を付け、旅の記録を右揃えで表示します。新しい記録が入ると表示し、更新がないまま3秒経つと一時的に消えます。記録は保存され、準備画面で引き続き確認できます。上下HUDとMAPは少し大きく表示します。

視界は四角形です。初期7×7マス、感覚の記憶で上下左右へ各1マスずつ広がり、最大15×15マスになります。壁による遮蔽と費用10→18→26→34ptは維持します。既存セーブにも読込時から適用し、取得段階や発見済み地形は保持します。

キャラクターレベルと経験値を追加しました。敵撃破で成長し、レベルアップごとに最大HP・現在HPが3増えます（仮バランス）。HPの左にLv.と経験値バーを表示し、攻撃・罠のダメージは受けたユニットの頭上へ赤字で表示します。旧セーブは進行を保ちLv.1／経験値0でv11へ移行します。レベルは旅ごとにリセットします。

探索画面はスマホ幅でフロア名・HPとアイコン・欠片を2段に整列します。図鑑・設定アイコンは端末で形が変わらないSVGです。ログはPC・スマホとも本文3行分を表示し、長文は折り返し、過去の内容はスクロールできます。

スマートフォン・PCのブラウザで遊ぶ、自動探索ダンジョンRPGの通常エンド版です。B30から30階を上り、地上1Fを目指します。

## 起動

Node.js 20以降で、リポジトリ内から実行します。外部パッケージのインストールは不要です。

```sh
node server.js
```

PCでは http://localhost:4317 を開きます。同じWi-Fiのスマートフォンからは `http://PCのLANアドレス:4317` にアクセスできます。必要に応じてOSのファイアウォールでローカルネットワークからの接続を許可してください。

## 遊び方

- タイトルのNewGameから目覚めへ進み、「思い出す」で探索を開始します。B30への支度画面はありません。初期12ptはB29到達後の準備から使えます。移動・戦闘・拾得は自動です。
- 速度は1倍・2倍・4倍。探索中は一時停止できます。指示変更は準備中のみで、ひとやすみ中も閲覧だけです。マップ下部に、現在の判断を自然な独り言の字幕で表示します。詳細な判断はステータス・ログで確認できます。
- 階段を上ると休息で最大HPの15%を回復し、次の準備画面へ移ります。
- 装備タブで武器・防具を交換します。本編の装備はすべて鑑定済み・呪いなし。拾得時の+値は維持します。
- 鑑定・解呪・合成はTRUE END後のエンドコンテンツとして後続制作します。現在の本編では利用できません。
- 探索指示はターゲット＋条件（AND）＋行動／スキルのカードで組みます。初期2行・1行4枚。指揮の記憶で最大8行、思考の記憶で1行最大6枚へ別々に拡張できます。編集は準備中のみ。再生の祈りは拾得後にカードで設定し、会心などはパッシブです。
- 画面上部の図鑑アイコンで攻撃力・防御力を確認できます。モンスターは視認時、装備は入手時に登録。装備は入手時から名前・能力を公開します。
- 図鑑を開いている間は停止し、閉じると元の停止状態へ戻ります。
- B1 Clear後「地上1Fへ」で通常エンド。次の旅では能力・記憶の欠片・装備をリセットし、図鑑と通常エンド記録を引き継ぎます。
- 絆の記憶は削除し、通常エンド達成後はB15で手紙を入手できます（代替条件を仮採用）。TRUEエンド本編は後続制作のため、現版は手紙があっても通常エンドに進みます。設定上は息子へ手紙を差し出す骸が崩れ、息子は父と確信できない結末です。

序盤は剣技・守護を上げ、装備を集めて交換することが助けになります。ドロップで取得する再生の祈りや指示枠の拡張も活用してください。

## 保存

端末のブラウザに自動保存します。再読み込み後の探索は一時停止状態で復帰。別タブへ移ったときも停止します。保存できない場合は記録欄に表示します。

通常版は `abyss-normal-v2` に保存し、旧5階試作の `abyss-prototype-v1` は変更せず残しています。旧版の旅からの自動移行は行いません。図鑑・達成記録も端末内の保存で、他端末との同期はありません。

## 構成・検証

- `data.js`：10区間・22種の敵・20種の装備・購入能力5項目・報酬6種・敵別のドロップ表。
- `game-engine.js`：探索・戦闘・装備・周回・図鑑・保存検証。`engine.js` は公開用の入口。
- `app.js`：画面操作、仮ドット絵のCanvas描画、効果音、自動保存。
- `style.css` / `screens.css`：既存画面のレスポンシブ表示。見栄えの磨き込みは後続作業。

```sh
node --test
```

自動テストで、全30階・複数シードの地形連結、戦術指示、装備交換・本編での旧機能無効化、図鑑、周回、保存、通常エンドまでの進行に加え、B15メッセージ、入手順、一覧の分類、旧保存の移行、デバッグ操作を検証します。素材は既存のオリジナル仮ドット絵を使用し、効果音はWeb Audioで生成します。

準備画面は探索指示→装備→スキルツリーのメニューを表示し、スキルツリーには2分類・5項目の一覧、右に探索と共通のステータスを表示します。装備・図鑑は武器／防具タブごとに入手順（初期選択）・攻撃順・防御順で並べ替え可能です。通常宝箱は4候補・各35%の配置抽選です。

ヘッダーの「オプション」→「デバッグモード」では指定階への移動・1階スキップ・HP回復・記憶の欠片追加・スキル最大化・装備生成・JSONセーブの書き出し／読み込み・初期化ができます。実際の保存へ反映されるため、確認用の進行を残す場合は先に書き出してください。初期化は確認後に実行し、旅だけの初期化では図鑑・達成記録を残します。

保存形式は現在v11です。旧セーブは各版を経由して移行し、能力・装備・図鑑・指示・手紙・進行を可能な限り保持します。移行条件と補償の詳細は仕様書を参照してください。`skill-tree.js` は一覧の分類、`debug-tools.js` はデバッグ処理を管理します。

スキルツリーは「ステータス」「探索指示枠」「スキル」のカード一覧です。ノードと接続線は表示せず、効果・前提・費用を常時確認し、各カードのボタンから習得します。

難易度を強化し、敵6〜10体・敵能力上昇・最低被ダメージ20%・泉2個（10HP回復）・階段後の休息15%に変更しました。新しい敵と泉の配置は次の階から適用します。

階段到達後の「Clear」メッセージ内で、記憶の欠片の獲得と次階の敵・異変を確認できます。独立した「勇者の残響」欄は削除しました。B30以外ではモンスターハウス12%・トラップハウス12%・霧16%（異変なし60%）を抽選します。B15の手紙は通常エンド達成が必要（仮採用）です。TRUEエンド本編は後続制作です。

探索画面は主人公の視界に合わせたズームカメラで追従します。右上にグリッド付きの半透明ミニマップ、マップ下部の帯に思考字幕と「ひとやすみ／探索を再開」、マップ直上に階数・HPバーと現在値／最大値・ATK・DEF・視界範囲・記憶の欠片を表示します。トラップハウスの罠は常時見え、通常階にも25%の確率（異変なしの階のみ）で1〜2個の罠が現れます。B20・B10は固定マップの中ボス階で、撃破すると階段の封印が解けます。

冒頭の副説明文を削除し、余白を詰めています。旧セーブもそのまま利用でき、過去ログと次階ヒントの内容は保持されます。

感覚の記憶は視界半径+1マス×4段階（初期3、最大7）。費用は10→18→26→34ptです。霧では2マス減少します。旧セーブの取得段階は維持し、新効果を適用します。追加請求はなく、次回購入から新コストです。

タイトルの英語名はThe Remains' Journey。サブタイトルを横に置き、章紹介や画面案内の独立見出しを削除しました。オプションを開くと探索は停止し、デバッグを閉じてもオプションが開いている間は停止を続けます。

UIは落ち着いた仮グレーテーマです。速度ボタンは探索画面の下部にあります。Clear後の「準備画面へ」は報酬文直下、準備の「探索を始める」はB〇〇への支度の直下にあります。初期化が必要な場合はオプション内のデバッグを利用します。

準備画面では出発ボタンの右に「あきらめる」、その下に準備中の操作説明があります。あきらめるは確認後にB30から新しい旅を開始し、図鑑とエンド達成記録を保持します。装備欄の「最強装備」で、武器は強化値込み攻撃力、防具は防御力が最大の所持品へまとめて交換できます。同値なら現在の装備を維持し、追加費用はありません。

ゲーム画面の上部レターボックスに階層〜記憶の欠片と速度変更、下部に字幕とひとやすみ／探索を再開を配置しています。上下帯は通常56px・狭い画面96pxで、ゲーム画面との境界線はありません。

探索中の「旅の記録」はゲーム画面と同じフレーム内で、下部レターボックスの下に表示します。スマホでも記録を含むゲームフレームの後にステータス・探索指示が並びます。

旅の記録は約7行分を表示し、長文は折り返し、古い記録はスクロールで確認できます。初期視界は半径3マスです。既存セーブにも新しい視界を適用し、感覚の記憶の取得段階と発見済み地形は保持します。


敵の撃破時は、通常22%・重装30%・中ボス100%でドロップ有無を判定し、成功時のみ敵ID別の重み付き表で装備・鍵・再生の祈りを選びます。床のコモン品は薬草または記憶の欠片。新しい宝箱は鍵1個で開封し、会心・吸命・追撃・窮地の転移・罠を見切るのいずれかを取得します。確率・数値は仮採用で、詳細はSPEC第22節です。

戦闘スキルは取得時に自動適用し、特殊指示は指示枠へ設定します。再生の祈りと戦術判断はポイントで購入できません。取得報酬はその旅だけ有効で、重複は欠片5ptへ変換。スキル図鑑（ヘッダーの✧）は6種類の取得記録を周回で保持します。鍵の数と今回の報酬一覧は右ステータスへ表示。デバッグには鍵追加・報酬選択取得があります。

旧セーブの現在階・未開封の装備箱は保持し、旧箱は鍵不要のままです。新しい階から鍵付き箱とコモン品を適用します。保存に抽選状態も含めるため、再読み込みで次の結果だけを引き直すことはできません。敵ごとのrate／entriesと報酬のweightはdata.js、抽選はdrop-system.jsで管理します。

調整用の固定方針の通しプレイは `node scripts/balance-audit.js 10` で再現できます。これは特定の指示・育成方針によるサンプルで、プレイヤー全体のクリア率ではありません。

難易度の仮調整では通常敵・重装敵の攻撃力を1上げ、中ボスの能力は維持しました。泉は10HP、階上昇時の休息は15%。通常階のコモン品2個は各25%で薬草（10HP）、75%で欠片（+3pt）です。

「ひとやすみ」を押すとマップ中央に休憩表示が出ます。下部帯の「探索を再開」で旅を続けます。再読み込みやタブ移動後の停止状態でも同じ表示になります。

GitHubへのpush・PRごとにActionsの「Game tests」で自動テストを実行します。更新時は自動テストとPagesデプロイの成功に加え、公開ゲームURLでも変更した動作を確認します。結果はIMPLEMENTATION_NOTES.mdに記録します。

探索指示の追加・削除・並び替え・条件変更は準備中だけ可能です。探索中に取得した特殊指示も、次の準備から設定できます。既存の指示設定と保存形式v9は保持します。

ブラウザ用JS・CSSの修正後は `node scripts/update-assets.js` を実行してindex.htmlもコミットします。配信URLの内容ハッシュで古いキャッシュを避けます。GitHubのテストでも生成漏れをチェックします。公開済みの更新はページを通常再読み込みすると適用されます。

カード式指示の保存はv10。旧セーブの指示を自動変換します。再生所持で空き行がある場合は回復行を補います。満杯の場合は次の準備で再生を設定してください。1周目のスキルツリー制限は未決定です。


探索画面はブラウザ内の最大16:9で表示します。ログは休止ボタン上に更新時から3秒間表示し、クリックで開く操作は不要です。ログを読んでいる間も探索が続くため、止める場合は「ひとやすみ」を使います。思い出の文章は骸の思考の上、詳細な能力と指示一覧は歯車→「この旅の状態・探索指示」で確認できます。準備画面はPC・横向きでは同じ16:9、スマホ縦向きでは画面の高さを使います。

ログとMAPは枠や見出しを付けず、内容だけ表示します。MAPは部屋に入ると壁・床を全体表示し、一度入った部屋はその階で表示を維持します。未入室の部屋は非公開で、主画面の視界とAIは変わりません。スマホでは最初の開始／再開タップから横向き全画面を試します。歯車から手動操作も可能です。ブラウザが対応しない場合は端末を横へ向けて遊べます。仕様上、[全画面の要求にはユーザー操作](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)が必要で、[横向き固定の対応](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)もブラウザに依存します。


LoadGame後に保存階層・レベルを確認し、「旅を再開する」で開始します。キャンセルでタイトルへ戻ります。骸／倅のロゴは同じ幅の表示枠です。
